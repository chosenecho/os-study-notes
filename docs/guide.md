# 学习指南

本项目面向按课程大纲复习的自考考生，提供独立编写的讲解、自编练习与交互实验。先到[课程目录](courses/index.md)确认教材版本和章节范围；多媒体课程仍为学习草稿。

1. **选课与定位**：从课程概览选择章节，利用复习导航按考点找讲解与题目。
2. **读完再作答**：章节题默认折叠答案，先自行列条件、写步骤，再展开核对。交互实验用于检验模型，自测用于回查薄弱点。
3. **记录与回看**：勾选“本章已复习”记录完成度。首页分别提供最近阅读和首个未完成章节；自测可重练错题。

## 保存范围

进度、字号、阅读位置和自测记录只保存在当前浏览器，不上传服务器，也不跨设备同步。清除站点数据会删除这些记录；隐私模式或存储被禁用时，只保证当前页面可用，请自行保存需要长期保留的结果。

## 阅读与操作

章节工具栏可调整字号。宽表格、代码和公式可横向滚动，键盘用户可先用 Tab 聚焦滚动区域。插图默认适屏显示，打开后可切到原图模式查看细节；Escape 关闭弹层。打印时章节答案会展开，打印结束后恢复折叠状态。

## 版本和反馈

课程笔记、题目与图示均不标作真题、官方答案或预测题。旧版协议、产品与算法简化模型以所在章节的条件为准。检查通过不代表教材已终校。

遇到问题请从[版本与勘误](errata.md)提交页面链接、位置、现有表述、建议修改和可核对依据。许可及权利反馈见[许可与版权](licensing.md)。
