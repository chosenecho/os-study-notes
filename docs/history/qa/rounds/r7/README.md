## 核对来源

优先对照本地教材：`资料/教材/操作系统概论/操作系统概论（2017年版）.md` 的页面置换、工作集与文件地址结构，以及 `资料/教材/计算机组成原理/book.md` 的数据对齐、Flash、Cache 与平均访问时间。教材均为本地 OCR 复原件，原有图像、题设与附录勘误仍按各章说明处理。
