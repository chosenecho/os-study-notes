## 2. B1 · P0 公式渲染（R2-01）

### 方案：自托管 KaTeX（比 MathJax 小 3–4 倍，355 个公式的命令集全部支持）
已核实：LaTeX 命令只用到 `\text \times \mathrm \cdots \mu \sim \left \right \approx \log \bmod \lfloor \rfloor \leftarrow \max \mathbf \oplus \sqrt \frac \pm \boldsymbol \vdots \Delta \quad \ll \leq \qquad \begin{aligned}`，**KaTeX 全部支持**；npm registry 可达，`npm pack katex@0.16.11` 实测下载成功（1.47 MB tgz，含 dist + 60 个字体）。

### 改动
1. **取依赖**（一次性）：
   ```powershell
   cd $env:TEMP; npm pack katex@0.16.11
   tar -xzf katex-0.16.11.tgz
   # 拷贝到站点源（构建时随 src 整目录复制到 docs）
   站点/src/assets/katex/katex.min.js
   站点/src/assets/katex/contrib/auto-render.min.js
   站点/src/assets/katex/katex.min.css
   站点/src/assets/katex/fonts/*.woff2      # 只要 woff2，约 300 KB
   ```
2. **`站点/mkdocs.yml`**（当前 70–73 行）：
   ```yaml
   extra_css:
     - assets/notes.css
     - assets/katex/katex.min.css
   extra_javascript:
     - assets/katex/katex.min.js
     - assets/katex/contrib/auto-render.min.js
     - assets/math.js
     - assets/interactions.js
   ```
3. **新建 `站点/src/assets/math.js`**：
   ```js
   (() => {
     const render = () => {
       if (!window.renderMathInElement) return;
       window.renderMathInElement(document.body, {
         delimiters: [
           { left: '\\(', right: '\\)', display: false },
           { left: '\\[', right: '\\]', display: true },
         ],
         throwOnError: false,
         ignoredClasses: ['md-search-result', 'md-nav__title', 'md-header__topic'],
       });
     };
     if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', render);
     else render();
   })();
   ```
4. **`站点/src/assets/notes.css`** 追加：
   ```css
   .arithmatex { font-size: 1.02em; }
   .katex-display { overflow-x: auto; overflow-y: hidden; padding-block: .35rem; }
   @media print { .katex { color: #111 !important; } }
   ```
5. **CSP**：`script-src 'self'`、`font-src 'self' data:` 已满足，`_headers` **不需要改**（自托管）。
6. **搜索索引**：索引是构建期纯文本，KaTeX 只影响渲染，无需处理。

### 验证（红转绿）
- 6 章 `.arithmatex` 355 → `.katex` 355、`.katex-error` **0**；
- `window.renderMathInElement` 存在，无 CSP 违规、无 console error；
- 390 宽下无横向溢出（`.katex-display` 自带横向滚动）；
- 打印预览公式可读；
- 首屏新增资源：katex.min.js + auto-render + css（字体按需），记录字节。
- 复跑：`node qa/r2/content/scripts/<公式脚本>.mjs`、`qa/r2/_lead/probe-math.mjs`。

### 回退
若个别公式报错：`throwOnError:false` 会显示红色原文，不阻断其他公式；必要时整体换 MathJax 3（`npm pack mathjax@3`，改 3 行加载路径）。
