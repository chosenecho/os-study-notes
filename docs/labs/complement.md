## 模型约定

n 位补码范围为 −2^(n−1) 到 2^(n−1)−1。只保留低 n 位，并按有符号补码解释。加法同号相加结果异号表示溢出；减法可以直接比较真实差值是否越界。

这里显示的是带符号溢出，不将最高位进位当作同一标志，也不约定具体 ISA 的减法进位/借位标志。可试 `-128 - 1`、`-128 - -128`、`-1 + 1`。

## 自编算例：有符号溢出不等于输出进位

采用 8 位补码，表示范围为 −128 至 127。输入 100 + 40：两个操作数的位模式分别为 `01100100` 和 `00101000`，相加得到 `10001100`。没有第 9 位输出进位，但数学结果 140 超出有符号上界；低 8 位按补码解释为 **−116，发生有符号溢出**。

再看 −1 + 1：位模式 `11111111` 与 `00000001` 相加得到 `1 00000000`。输出进位为 1，截断结果为 0，数学结果也为 0，**没有有符号溢出**。输出进位依据无符号位模式的加法，有符号溢出依据带符号表示范围；二者不能相互替代。运算部件与标志的讲解见[进位与有符号溢出](../courses/computer-organization/chapter-02.md#s7)。
