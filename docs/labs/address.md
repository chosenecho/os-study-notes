# 分页地址转换练习

输入页大小、逻辑地址与页表，计算物理地址或判断缺页、越界。

## 模型约定

按字节编址，页号和物理块号从 0 开始。页表第 n 项对应第 n 页；`-` 表示该页合法但尚未驻留。超出页表范围表示地址越界，和缺页不同。这里不模拟 TLB、访存耗时或缺页后的调入。

页号 = ⌊逻辑地址 ÷ 页大小⌋；偏移 = 逻辑地址 mod 页大小。物理地址 = 物理块号 × 页大小 + 偏移。

把地址改成 `3072`、`4096`，分别观察缺页与越界。

## 自编算例：2500 怎样转换为物理地址

按字节编址，页大小为 1024 B，逻辑地址为 2500；页表第 0 至 3 项依次为物理块 5、2、7、未驻留。

1. 2500 = 2 × 1024 + 452，因此页号为 2，页内偏移为 452 B。
2. 第 2 页驻留在物理块 7，转换时保留页内偏移。
3. 物理地址为 7 × 1024 + 452 = **7620**。

地址 3072 对应第 3 页，偏移为 0，该页未驻留，应触发缺页；地址 4096 对应第 4 页，已超出这张页表的合法范围。两种情况都不能直接生成物理地址。页号、页框与偏移的关系见[分页与地址变换](../courses/operating-systems/chapter-04.md#s4)。
