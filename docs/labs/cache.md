# Cache 映射练习

输入行数、块大小与地址序列，查看直接映射的行号、标记、命中和替换。

## 模型约定

按字节编址，Cache 初始全无效；每次都是读访问，整块装入。不计预取、写策略和多级 Cache。

主存块号 = ⌊地址 ÷ 块大小⌋；行号 = 块号 mod 行数；标记 = ⌊块号 ÷ 行数⌋。命中要求该行有效且标记相同；块内偏移不会影响标记判断。

先观察 `0 4` 是否命中同一块，再观察 `0 64 0` 为什么会冲突。

## 自编算例：直接映射中的冲突

4 行直接映射 Cache，每块 16 B，初始全无效；按字节地址依次读 0、4、16、64、0、16。地址 64 对应块号 4、行号 0、标记 1、块内偏移 0。

| 字节地址 | 主存块号 | 行号 / 标记 | 结果 |
| --- | --- | --- | --- |
| 0 | 0 | 0 / 0 | 不命中 |
| 4 | 0 | 0 / 0 | 命中 |
| 16 | 1 | 1 / 0 | 不命中 |
| 64 | 4 | 0 / 1 | 不命中 |
| 0 | 0 | 0 / 0 | 不命中 |
| 16 | 1 | 1 / 0 | 命中 |

共 **4 次不命中、2 次命中**。地址 4 与地址 0 同属块 0，偏移不同不影响命中。块 4 与块 0 都只能放到第 0 行，标记不同，读取 64 会替换原行，随后再读 0 又不命中。第 1 行未被替换，最后读 16 仍命中。映射方式与地址字段见[Cache 映射与性能](../courses/computer-organization/chapter-05.md#s5)。
