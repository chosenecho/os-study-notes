## 1. 目标规范（canonical spec）

### 1.1 12 章统一骨架

```markdown
# 第 N 章 <章标题>

> 依据：《<书名>》（<年版>）第 N 章、配套自考大纲及附录答案。下文编号指大纲“考核内容与考核要求”；标注“自编”的算例为学习辅助，不是真题。

## 复习导航：大纲要求与笔记位置

| 大纲条目 | 层次 | 位置 | 学完应能做到 |
|---|---|---|---|
| 1.1 …、1.2 … | 识记 | 第 1 节 | … |

## 本章学习目标

<整章主线 1 句。>

<读法/易错点 2–3 句；不重复表格里的逐条目标。>

## 1 <节标题>（<大纲号>，<层次>）
…

## N 考核要求

本章共 N 条考核条目：识记 x、领会 y、简单应用 z、综合应用 w。本章重点为…；难点为…。

## N 教材本章习题

题目取自教材第 N 章「习题/思考题与练习题」（共 M 题），答案取自教材附录「部分习题解答/参考答案」（收录第 … 题；其余请对照教材自行完成）。

### N.1 <组名>
…

## N 闭卷复习与跨章联系（补充）
…
```

硬性规则：
- `本章学习目标`、`考核要求`、`教材本章习题`、`闭卷复习…` 四个 h2 必须存在，顺序固定；`本章学习目标` 无编号。
- 内容节 h2 编号 1..N 连续；`考核要求` 紧随最后一个内容节；`习题`、`闭卷` 排最后两位。
- 所有内容节标题带“（大纲号，层次）”；多条目用“、”，范围用“–”，层次用“、”。
- 复习导航表 4 列、一行对应一个内容节；同节多条大纲合并到首列。
- 依据块同书六章长度差 ≤ 20 字；课程特殊约定（KB=1024 等）放课程 README 或第二句，同书一致。

### 1.2 习题区规范

- **分组**：每章习题节下 3–4 个 h3 组；OS 按题型（单选/填空/简答/综合应用），CO 按主题（概念与简答/…）；组名同书同章法，组标题格式 `### N.M <组名>`。
- **编号**：题号全章唯一、连续 `1..N`（OS 现在组内重编号，改为全章连续；CO 保持原连续）。组标题可带范围：`### 12.1 概念与简答（第 1–4 题）`。
- **题首**：一律 `**N. <题干>**`（整句加粗），不再出现 `**N.** 题干`、`**教材原题：**`、`**题目：**` 混用（hooks 保留别名兜底）。
- **答案**：每个 `.exercise-item` 必须有且只有一个 `<details class="exercise-answer">`；答案首行统一 `**参考答案：**`，正文另起一段；无答案题渲染占位 details：`教材附录未收本题解答，请对照教材自行完成。`
- **导入语**：统一 CO 模板（共 M 题 + 附录收录题号 + 其余自行完成）。
- **填空**：ASCII `___`；选择题占位统一 `【　】`（全角空格）。
- **摘要**：`答案与解析`；details 加 `id="answer-N"`（可选深链）。
- **打印**：`beforeprint` 打开全部答案，`afterprint` 还原；不再依赖 CSS `display` 强制展开。

### 1.3 插图规范

```markdown
![图N-M <标题>](图/<文件名>.svg)

*图N-M <标题>*
```

- 只用 Markdown 语法（OS1 的 8 张原始 `<img>` 改造）；图后空一行再写斜体图注。
- 不写 `width`/`height`（由 CSS 控制）；`notes.css` 改 `width:auto; max-width:100%; margin:0 auto`，按 SVG 原生尺寸渲染。
- 图注 `图N-M <标题>`，图号按出现顺序递增；图注样式 14px、次要色、居中。
- 同一图只出现一次；图号与正文引用一致。
- 无图页不输出 `image-dialog`。

### 1.4 公式规范

- 独立公式用 `$$…$$`，行内用 `$…$`；单位用 `\text{}`，乘号 `\times`，空格 `\,`。
- 超宽公式用 `\begin{aligned}` 断行，禁止依赖横向滚动。
- OS 页注入 KaTeX 的条件改为“正文含 `class="arithmatex"`”，不再按目录硬编码。
- 验收：`.katex-error = 0`；1440/390 及打印态 `scrollWidth <= clientWidth + 2`。

### 1.5 术语/单位/标点规范

**术语**（不强行跨书替换，按书内主词 + 首现别名 + 两书对照表）：
- OS：主词“内存”（首现“内存（主存）”，章名“内存管理”保留）、处理机/处理器按教材节名（首现“处理器（处理机）”）、“页框”（首现“页框（页帧）”）、“外存”、“快表（TLB）”。
- CO：主词“主存”（首现“主存（内存）”）、“处理器/CPU”、“页框”（首现“页框（页帧）”）、“辅存（外存）”、“Cache（高速缓存）”。
- 同形异义：OS 的“通道”写“I/O 通道”；CO 写“内存通道/存储通道”。
- EAT/AMAT：`有效访存时间 EAT（AMAT）`；符号 `m` 必须随章定义（OS=m 内存访问时间；CO=m 缺失率）。
- 两书 README 共用一张“术语对照表”，列出上表与首现别名。

**单位/数字**：
- 容量统一 `KB/MB/GB/TB`（按 1024 进位），每书章首或 README 写一次；CO 的 6 处 KiB、3 处 MiB 换算成 KB/MB。
- 千分位统一半角空格（`10 000 000`）；表格内可不用分隔。
- 进制散文统一 `…H` / `…B`；`0x` 只留 C 代码。
- 数字范围统一 `–`（en dash）；散文转折才用 `—`。

**标点/空格**：
- 中英文之间加半角空格（CO 304 处补齐；OS 已 0 违规）。
- 中文引述统一 `“”`；`「」` 只留 UI 标签/嵌套引语。
- 别名统一全角括号 `（ ）`（CO 的 `外设(I/O 设备)` → `外设（I/O 设备）`）。
- 表分隔行统一 `| --- | --- |`（源层；渲染无差异）。

### 1.6 交叉引用规范

| 场景 | 写法 | 渲染 |
|---|---|---|
| 本课程跨章 | `见第 N 章` / `见第 N 节` | hooks 转 `chapter-N.md` 链接 |
| 教材章 | `教材第 N 章` | 不链接 |
| 跨书 | `见《计算机组成原理》第 N 章` / `见《操作系统概论》第 N 章` | hooks 转跨目录链接 |
| 本章内 | `本章第 N 节` | 不链接 |

- hooks 只对带“见”的引用建链；裸“第 N 章”保持纯文本，避免误链教材页。
- 构建期校验：`第 N 章` 的 N ∉ 1..6 且无“教材”前缀 → warning；`第 N 节` 超过该章节数 → warning。
- 统一“第 N 章/第 N 节”带半角空格；CO 的 2 处无空格修掉。

### 1.7 站点 chrome 规范

- 页脚 prev/next 与正文 `chapter-nav` 二选一：推荐移除 `mkdocs.yml` 的 `navigation.footer`，只留正文一套书内导航（边界页指向课程列表）。
- meta description 改“含大纲要求、重点讲解与教材习题（部分附答案）”。
- 无图页不输出 `image-dialog`。
- 表格提示条字号固定 13px，不受习题答案 `font-size:.95em` 影响；提示在构建期预置，避免 400ms 后顶高页面。
- CO 9 列表在桌面拆成两表或降字号，保证 1440 下不超 760px。
- 打印：`beforeprint` 打开答案；公式断行；用 CDP `printToPDF` 回归，不用 `emulateMedia` 判定。

## 3. 验收脚本（新建 `qa/r3/verify-consistency.mjs`）

> 目标：把“两书一致”变成可执行断言，而不是目测。默认 base `http://127.0.0.1:8123`，12 页逐页跑；每条失败打印实际值。

```js
// 结构
assert(doc.h2[0].text === '复习导航：大纲要求与笔记位置');
assert(doc.h2[1].text === '本章学习目标');

assert(doc.h2.at(-1).text.match(/^\d+ 闭卷复习与跨章联系（补充）$/));
assert(doc.toc.entries.length === doc.h2.length + doc.h3.length);
assert(doc.h3.every(t => /^\d+\.\d+\s/.test(t)));
assert(doc.contentH2.every(t => /（[^）]+，[^）]+）$/.test(t)));

// 复习导航
assert([...thead].join('|') === '大纲条目|层次|位置|学完应能做到');

// 习题
assert(exerciseItems === details);
assert([...details].every(d => firstText(d).startsWith('参考答案') || /教材附录未收/.test(firstText(d))));
assert(exerciseSection.querySelectorAll(':scope > p:not(details p)').length === 0);
assert(nums.every((n, i) => i === 0 || n === nums[i - 1] + 1));
assert(groups.length >= 3 && groups.length <= 4);

// 引用
assert(!/第\s*[7-9]\s*章/.test(articleText));
assert(!/第\d+章/.test(articleText)); // 无空格
assert(crossBookLinks.every(a => a.href.includes('/chapter-')));

// 图/公式
assert(OS figurePages.every(p => p.imgs.every(i => i.alt === i.caption && !i.alt.includes('_'))));
```

## 5. 风险、回滚与边界

### 5.1 风险
| 风险 | 概率/影响 | 缓解 |
|---|---|---|
| OS 节号顺延导致“第 N 节”引用错位 | 中/高 | B2-6 逐条解析 116 处引用；构建期加“第 N 节 ≤ 节数”校验；改完跑链接脚本 |
| OS 题号全章重排，读者已有的“第 N 题”记忆失效 | 中/中 | 在每章习题导语加一句“题号按本章顺序重排”；不引用旧题号 |
| 复习导航表重排丢行 | 中/中 | 脚本从旧表生成新表，人工对照行数 == 节数；diff review |
| CO 习题补组打乱教材原题顺序 | 低/高 | 只加 h3 分界、不移动题目；题号保持 1..N；若必须移动，放弃 D2-A 改用扁平 |
| KaTeX 迁移出现 `.katex-error` | 中/中 | `throwOnError:false`；逐章跑 `katex-error=0`；失败则回退该章为纯文本 |
| 打印规则跨引擎不生效 | 中/低 | `beforeprint` JS 兜底；用 Chrome/Firefox 各导出一次 PDF 抽检 |
| 页脚移除导致移动端少导航 | 低/低 | 保留正文 `chapter-nav`；移动端抽检 390 |
| 术语批量替换误伤教材原题/代码 | 中/高 | 只替换正文，跳过 `details` 内教材原文与代码块；逐条 review |

### 5.2 回滚
- 每批一个 git commit（或分支 `r3-consistency`），`git revert <sha>` 可整批回滚。
- `站点/docs/`、`站点/dist/` 是派生目录，不提交；回滚后重新构建即可。
- B4 公式迁移按章提交，单章可回退；KaTeX 注入是全局开关，可回退 `hooks.py`。
- 术语替换保留“旧→新”映射 CSV（`qa/r3/term-map.csv`），可反向还原。

### 5.3 不在本轮范围
- 不重写正文语气/文风（R2 的“去 AI 腔”已做过一轮）；只改结构与标记。
- 不给 CO 加插图，不给 OS 加 KaTeX 以外的数学内容；不统一两书的内容深度。
- 不改教材事实、不改考点；中断/异常等口径只加“跨书对照”注记。
- 不改 URL、不拆页面（符合“够用即可，不做结构性性能改动”的偏好）。
- 不自动部署；B6 部署前需要用户确认。
