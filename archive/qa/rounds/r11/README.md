# R11：增加交互练习

在现有进程调度实验之外，新增五个可改参数的计算实验和一套 24 题随堂自测，共七类练习。教材笔记和教材原题未在本轮改写。

生产入口：https://studynote.chosenecho.dpdns.org/lab/

## 内容与用法

| 新增练习 | 能练什么 | 关键边界 |
| --- | --- | --- |
| 页面置换 | FIFO、LRU、OPT；预测缺页次数，逐步查看页框和淘汰页 | 初始为空，首次装入算缺页；FIFO 命中不改装入次序；OPT 为离线参照 |
| 银行家算法 | 编辑资源向量和矩阵；查安全序列；试分配请求 | 先查 Need 与 Available，再查安全性；不安全不等于死锁；运行不修改原输入状态 |
| 分页地址转换 | 拆页号与偏移，查页表并形成物理地址 | 区分驻留、缺页和地址越界；按字节编址；不模拟 TLB |
| Cache 映射 | 直接映射的块号、行号、标记、块内偏移和冲突 | 初始无效；只读、整块装入；不推广到组相联或写策略 |
| 补码加减 | 预测有符号溢出，查看输入编码与截断结果 | 输入必须在所选位宽范围内；区分数学结果和低位模式；不混用进位与溢出 |
| 随堂自测 | 两门课各 12 题，每章 2 题；即时解析、章节回查、错题重练 | 题目自编，不冒充教材原题或真题；本轮状态仅在当前页面保存 |

现有调度实验补充了“同时到达”和“大时间片”两组边界练习。首页和侧栏增加统一入口，每个实验有适用模型、手算示例与对应章节链接。

计算实验先填写预测，再运行核对；过程支持上一步、下一步与全部展开。参数修改后清除旧结果，输入错误就近标明并聚焦对应字段。恢复示例会重置参数、预测与错误提示。自测提交后锁定选项，避免重复计分；完成后可只重练本轮错题。

## 实现位置

- `站点/src/lab/`：七类练习与入口页。
- `站点/src/assets/labs-core.mjs`：纯计算模型，可直接被 Node 核算脚本导入。
- `站点/src/assets/quiz-bank.mjs`：24 题及解释、课程章次和回查链接。
- `站点/src/assets/labs.mjs`、`labs.css`：交互与局部样式，沿用阅读站点的亮暗主题变量。
- `站点/src/assets/lab-loader.mjs`：仅练习页加载模型和题库，普通章节阅读不下载这些模块。
- `站点/src/_headers`：为新增的稳定文件名资源设置短期可重新验证缓存。

未引入新的前端依赖、远端字体或服务端数据保存。模型自测已接入既有 CI；Playwright 浏览器检查仍由本机运行。
