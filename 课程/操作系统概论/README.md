# 操作系统概论：全六章笔记导航

这套笔记按教材六章铺开，依据是课程目录里的《操作系统概论（2017 年版）》和书前的自学考试大纲。每章先标明大纲的考核范围与能力层次，再用教材的讲法解释概念和机制，章末配上教材例题与本章习题。习题取自各章「思考题与练习题」，答案以教材附录「部分习题参考答案」为核对依据。

两门课共用的速查在 `课程/` 根目录：[术语与缩写表](../术语与缩写表.md)、[易错点清单](../易错点清单.md)。

## 考核层次

- **识记**：能独立给出定义、列出构成，并准确辨别名称。
- **领会**：能解释机制、比较差异，并根据条件跟踪算法过程。
- **简单应用**：能把给定规则用于明确场景，写出必要步骤。
- **综合应用**：能把多个知识点组合起来建模、计算、说明结论。

第二章信号量、第四章分页及二级分页、第五章目录与地址结构属于综合应用内容，需要结合具体条件建模和计算。第三章周转时间与银行家算法要求简单应用。页面置换和磁盘调度虽列为领会层次，也需要理解规则并跟踪执行过程。

## 考试说明

命题规定：闭卷笔试 150 分钟；识记 30%、领会 35%、简单应用 20%、综合应用 15%；难度按易、较易、较难、难 3:3:3:1；重点内容不少于 60%；题型有单选、填空、简答和综合。各章「考核要求」只写该章的条目统计与重点/难点，课程级的分值权重以本节为准，不逐章重复。

## 术语与写法约定

| 概念 | 本课用词 | 首次出现 | 与另一门课的关系 |
|---|---|---|---|
| 主存 / 内存 | 内存 | 内存（主存） | 计算机组成原理以「主存」为主词 |
| 处理机 / 处理器 / CPU | 处理器（教材节名「多处理机调度」保留） | 处理器（处理机） | 计算机组成原理用处理器/CPU |
| 页框 / 页帧 | 页框 | 页框（页帧） | 两书都用页框 |
| 外存 / 辅存 | 外存 | 外存（辅存） | 计算机组成原理用辅存 |
| 高速缓存 | 高速缓存 | 高速缓存（Cache） | 计算机组成原理用 Cache |
| 快表 | 快表 | 快表（TLB） | 两书一致 |
| 通道 | I/O 通道 | — | 计算机组成原理的「通道」多指内存/总线通道 |
| 有效访存时间 | EAT | 有效访存时间（EAT） | 计算机组成原理称 AMAT |

写法约定：
- 容量按 1024 进位：`1 KB = 1024 B`，`1 MB = 1024 KB`；全书只用 KB/MB/GB，不混用 KiB/MiB。
- 地址、页号、块号默认从 0 开始编号；题目若另给起点，以题目为准。
- 磁盘调度例题为自编练习，均明确给出磁头初始方向与扫描边界；教材的传统磁盘与硬件模型只用于本课复习，不代表今天的产品参数。
- 伪代码用代码块，`P = wait`、`V = signal`；算式用 KaTeX（`$...$` / `$$...$$`），不写成等宽文本。
- 数字范围用 `–`（如 `1.1–1.2`）；散文转折才用 `—`。
- 中英文之间加半角空格；中文引述用 `“”`；同义别名用全角括号（如 `页框（页帧）`）。
- 表格分隔行统一 `| --- | --- |`；表头 4 列的「复习导航」一行对应一个内容节。

## 建议学习顺序

初学就按教材章节顺序读，每章对着开头的大纲表确认这次要考到什么程度。概念站住之后，再把 PV、进程调度、银行家算法、地址转换、页面置换、文件容量、磁盘调度这几类题集中过一遍，然后做章末的教材习题自检，哪一步卡住就回到对应小节重算。

「进程读一次文件」这条线索能把六章串起来。进程发系统调用请求读文件，文件系统顺着路径找到目录项和数据块，内存管理提供缓冲区与地址映射，设备管理组织真正的传输。数据还没就绪时进程进入阻塞；I/O 完成后系统把它唤醒、放回就绪队列，再由调度程序决定什么时候让它接着跑。

## 各章复习主线

| 章 | 一句话主线 | 最容易丢分的计算 |
| --- | --- | --- |
| 1 | 操作系统是怎么从无到有长出来、又靠什么特征被认出来的 | 中断响应四步、用户态与核心态的切换点 |
| 2 | 进程是资源分配与调度的基本单位，PCB 是它的身份证 | PV 操作的动作顺序、互斥与同步的判定 |

| 4 | 内存怎么分、地址怎么转、不够用时怎么换 | 二级页表地址转换、页面置换命中率、EAT |
| 5 | 文件怎么存、目录怎么找、空闲空间怎么记 | FAT 链追踪、最大文件长度、位图与索引块大小 |
| 6 | 设备怎么被管住、I/O 怎么被缓冲、磁盘怎么调度 | DMA 过程、磁盘调度移动距离、缓冲流转 |
