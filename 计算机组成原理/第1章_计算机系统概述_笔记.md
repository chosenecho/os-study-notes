# 第1章 计算机系统概述

> 依据：袁春风《计算机组成原理》（2016年版）教材第1章及配套自考大纲。教材位置：[第1章](教材/chapters/11_第1章%20计算机系统概述.md)；考核层次见[课程大纲](教材/chapters/04_Ⅲ.%20课程内容与考核要求.md)。本笔记的算例与自测为学习辅助，不是真题。

## 本章学习目标

本章介绍计算机系统的基本组成，以及程序在系统中执行的过程。硬件组成、软件分类和系统层次属于大纲中的领会要求；性能评价还要求能够完成简单计算。理解这些内容，需要将程序的转换过程与硬件的执行过程联系起来。

## 1.1 计算机硬件的基本组成

冯·诺依曼结构以**存储程序**为核心：指令和数据以二进制形式存放在存储器中，启动后自动取指、解释和执行。经典结构由运算器、控制器、存储器、输入设备、输出设备组成。指令与数据的区别取决于解释和使用方式，不能仅看二进制外观。

| 部件 | 作用 | 需要分清的概念 |
| --- | --- | --- |
| 运算器 | 算术、逻辑、移位等运算 | ALU是核心运算部件，寄存器暂存操作数及结果 |
| 控制器 | 取指、译码、发出控制信号 | 决定何时传什么、执行什么操作 |
| 主存 | 存放正在运行的程序与数据 | 按地址访问；不是CPU内部寄存器 |
| 输入/输出设备 | 与外部交换信息 | 通常经I/O接口连接系统 |
| 总线与互连 | 在部件间传递信息 | 地址、数据、控制信息的职能不同 |

现代系统通常以存储器为中心组织数据交换；CPU主要包含运算器和控制器。主存、CPU、I/O通过互连结构协同工作。辅存容量大、断电保持，用于长期保存；程序通常装入主存后才能被CPU执行。

## 1.2 计算机软件概述

软件包括程序以及相关数据、文档。系统软件管理资源并为应用提供环境，如操作系统、语言处理系统、数据库管理系统及工具软件；应用软件解决用户的具体问题。

- 操作系统管理处理器、存储器、设备和文件等资源，提供服务接口。
- 编译程序将高级语言源程序转换成目标代码；汇编程序将汇编语言转换成机器代码。
- 解释程序按源程序或中间表示逐步解释执行，不应理解为“先生成一个完整的独立机器程序再运行”。

高级语言的一条语句常对应多条机器指令。汇编指令通常与机器指令有较直接的对应关系，但伪指令可能展开成多条机器指令。

## 1.3 计算机系统的层次结构

同一个程序可以在不同抽象层次上描述。应用与算法说明要解决的问题，高级语言表达处理步骤，汇编语言和机器指令描述机器可以执行的操作。指令集体系结构（ISA）规定这些操作的含义，微体系结构和逻辑电路则负责实现它们。操作系统通过系统调用等机制提供资源管理服务，在ISA之上扩展程序的运行环境。

**ISA是软件与硬件之间的接口约定**，包括指令、寄存器、数据类型、寻址方式等程序员可见特性。微体系结构说明这些约定怎样实现，例如是否流水线、怎样组织数据通路。同一ISA可以有不同实现，其性能也可以不同。

硬件是软件运行的基础，软件决定硬件完成的具体工作；一些功能可以用不同软硬件组合实现，但时间、成本、灵活性会不同。应用程序员主要关心语言和库，系统程序员需要理解操作系统和ISA，硬件设计者关心数据通路与逻辑实现。本课程连接机器级程序与硬件实现。

## 1.4 程序开发与执行过程

典型C程序从源文件到运行，需要经过预处理、编译、汇编、链接和装入。预处理展开头文件和宏等内容；编译将处理后的源程序转换为汇编代码，汇编再生成可重定位目标文件。链接把目标模块及所需库代码组合起来，解决符号引用，形成可执行文件。装入阶段则将程序映射到运行所需的地址空间。

源文件通常是文本文件，保存的是字符编码；可执行文件包含机器指令、数据及装入信息。这一区别解释了为什么源代码不能直接作为机器指令执行。程序装入后，CPU通过以下部件完成指令的读取和执行。

| 名称 | 保存或完成的内容 |
| --- | --- |
| PC，程序计数器 | 指令地址；顺序执行时按指令长度更新，转移时装入目标地址 |
| IR，指令寄存器 | 当前取出的指令 |
| GPR，通用寄存器 | 操作数、中间结果、地址等 |
| ALU | 进行算术与逻辑运算 |
| 标志寄存器 | 零、符号、溢出、进位等状态信息，具体依ISA而定 |
| MAR / MDR | 存储器地址 / 与存储器交换的数据，第4章展开 |

执行指令时，CPU先根据PC给出的地址取出指令并送入IR，再对指令译码，确定操作类型和操作数来源。随后按寻址方式取得操作数，执行指定操作，并将结果写入目的位置。PC的更新使CPU能够继续执行后继指令。各类指令所需的步骤有所不同，例如分支指令主要改变执行顺序，存数指令则把结果写入主存。时钟协调状态更新，控制信号决定各部件在相应时刻执行的操作。

例如“将主存某单元加到寄存器”：必须先取到这条指令，再算出数据地址并读数据，最后相加写回。取指访问和取数访问的目的不同。

## 1.5 计算机系统性能评价

响应时间是完成一次任务所需时间；吞吐率是单位时间完成的任务量。比较性能必须使用相同工作负载和评价口径。

设指令数为IC，平均每条指令周期数为CPI，时钟频率为f，周期为T：

$$T=1/f，\qquad CPU时间=IC\times CPI\times T=\frac{IC\times CPI}{f}$$

不同指令类别占比为pᵢ时，平均CPI为Σ(pᵢ×CPIᵢ)。CPU时间区别于包含I/O等待等开销的总运行时间。

算例：程序执行10⁹条指令，平均CPI=1.5，主频3 GHz，CPU时间=10⁹×1.5/(3×10⁹)=0.5 s。若A执行需0.5 s、B需0.8 s，A相对B的加速比=0.8/0.5=1.6。

MIPS=IC/(执行秒数×10⁶)，在相同口径下可写成f/(CPI×10⁶)。MFLOPS统计每秒百万次浮点运算。不同ISA、指令功能、程序组成会影响指标，不能凭主频或MIPS单独判断所有任务的性能。基准程序通过代表性工作负载比较系统，但仍应说明负载和测试条件。

上述公式也说明了性能差异的来源。算法决定需要完成的工作量，语言和编译器影响生成的指令数及指令组成，ISA规定每条指令能够完成的功能。硬件组织进一步影响CPI和时钟周期。若评价的是整个任务的运行时间，还需要计入存储访问与I/O等待等因素。

## 自测题

1. PC与IR有什么区别？
2. 4 GHz机器一定快于3 GHz机器吗？
3. CPI为2的指令占25%，CPI为1的占75%，平均是多少？
4. CPU是完整计算机吗？
5. 能否用自己的话从源文件讲到执行第一条机器指令？

### 参考答案

1. PC给出地址，IR保存指令内容。
2. 还要比较指令数、CPI和负载。
3. 1.25。
4. 还需要主存、I/O等部件。
5. 应包含翻译、链接、装入、取指译码执行。
