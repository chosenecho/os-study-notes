## 建议用法

初学时适合按章节顺序阅读。第1章说明系统全貌，第2章讨论数据编码和运算，第3章用指令描述机器操作，第4章解释CPU的实现，第5、6章再说明存储和I/O如何配合执行。数据通路和电路部分需要结合教材原图，确认各部件之间的具体连接。

熟悉各章后，可以集中练习性能评价、补码与标志、IEEE编码、寻址与分支、流水线、芯片扩展、Cache、虚实地址转换，以及磁盘和I/O开销等计算专题。计算前明确位宽、编址单位、时延定义和初始条件，有助于区分形式相近但适用条件不同的公式。

章末自测可用于检查概念掌握情况，再通过教材习题和真题检验应用能力。整理错题时，除了结果，还应记录出错的条件判断、所用公式和单位；必要时用反例说明原有理解为何不成立。
