# 操作系统概论：全六章笔记导航

这套笔记按《操作系统概论（2017 年版）》的六章及书前自学考试大纲整理。每章先标明考核范围与能力层次，再解释概念和机制，章末配上教材例题与本章习题。习题取自各章“思考题与练习题”，答案以教材附录“部分习题参考答案”为核对依据。

两门课共用的速查在 `content/reference/` 目录：[术语与缩写表](../../reference/glossary.md)、[易错点清单](../../reference/pitfalls.md)。

## 考核层次

- **识记**：能独立给出定义、列出构成，并准确辨别名称。
- **领会**：能解释机制、比较差异，并根据条件跟踪算法过程。
- **简单应用**：能把给定规则用于明确场景，写出必要步骤。
- **综合应用**：能把多个知识点组合起来建模、计算、说明结论。

第二章信号量、第四章分页及二级分页、第五章目录与地址结构属于综合应用内容，需要结合具体条件建模和计算。第三章周转时间与银行家算法要求简单应用。页面置换和磁盘调度虽列为领会层次，也需要理解规则并跟踪执行过程。

## 考试说明

教材大纲规定考试为闭卷笔试，时长 150 分钟。能力层次比例为识记 30%、领会 35%、简单应用 20%、综合应用 15%；难度比例为易、较易、较难、难 3:3:3:1，重点内容不少于 60%。题型包括单选、填空、简答和综合。各章的“考核要求”列出对应条目与重点；课程级比例以本节为准。

## 术语与写法约定

| 概念 | 本课用词 | 首次出现 | 与另一门课的关系 |
|---|---|---|---|
| 主存 / 内存 | 内存 | 内存（主存） | 计算机组成原理以「主存」为主词 |
| 处理机 / 处理器 / CPU | 处理器（教材节名「多处理机调度」保留） | 处理器（处理机） | 计算机组成原理用处理器/CPU |
| 页框 / 页帧 | 页框 | 页框（页帧） | 两书都用页框 |
| 外存 / 辅存 | 外存 | 外存（辅存） | 计算机组成原理用辅存 |
| 高速缓存 | 高速缓存 | 高速缓存（Cache） | 计算机组成原理用 Cache |
| 快表 | 快表 | 快表（TLB） | 两书一致 |
| 通道 | I/O 通道 | — | 计算机组成原理的「通道」多指内存/总线通道 |
| 有效访存时间 | EAT | 有效访存时间（EAT） | 本课第 4 章重点计算缺页开销；组成原理第 5 章用 AMAT 分析 Cache，符号与条件须分别确认 |

写法约定：
- 存储容量默认按 1024 进位：`1 KB = 1024 B`，`1 MB = 1024 KB`。题目若另行约定容量或速率单位，应采用题设，并在代入公式前统一单位。
- 地址、页号、块号默认从 0 开始编号；题目若另给起点，以题目为准。
- 磁盘调度例题为自编练习，均明确给出磁头初始方向与扫描边界；教材的传统磁盘与硬件模型只用于本课复习，不代表今天的产品参数。
- 伪代码用代码块，`P = wait`、`V = signal`；算式用 KaTeX（`$...$` / `$$...$$`），不写成等宽文本。
- 数字范围用 `–`（如 `1.1–1.2`）；散文转折才用 `—`。
- 中英文之间加半角空格；中文引述用 `“”`；同义别名用全角括号（如 `页框（页帧）`）。
- 表格分隔行统一 `| --- | --- |`；表头 4 列的「复习导航」一行对应一个内容节。

## 建议学习顺序

初学时按教材章节顺序阅读，并先用章首大纲表确认范围与能力层次。理解概念后，再集中练习 PV、进程调度、银行家算法、地址转换、页面置换、文件容量和磁盘调度。最后用章末教材习题自检；有步骤不清楚时，回到对应小节重新推导。

可用一次阻塞式文件读取串联六章：进程通过系统调用请求读文件，文件系统沿路径定位目录项和数据块，内存管理提供缓冲与地址映射，设备管理组织传输。数据未就绪时，读进程阻塞；I/O 完成后被唤醒并进入就绪队列，再由调度程序安排继续执行。
