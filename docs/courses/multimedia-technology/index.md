# 多媒体技术及应用（第三版）

本课程以刘成明、石磊主编《多媒体技术及应用（第三版）》（清华大学出版社，2021 年）为知识范围，结合江苏省高等教育自学考试 13511《多媒体技术与应用》大纲（江南大学编，2024 年）组织九章复习。讲解采用本项目独立表述，练习为自编情境任务；能力层次用于复习定位，不代表现行考试公告。

!!! warning "学习草稿 · OCR 尚未终校"

    来源成书稿尚未逐字终校。各章标出来源疑点和软件版本边界；存疑表述不作为唯一答案。软件操作流程仍需在对应环境实测。

## 怎样复习

先用复习导航核对大纲条目，读完讲解后独立作答，再展开参考答案。计算题先写条件、单位和开销边界；操作题交代输入、过程、输出及验证记录，不能把口述步骤当作已经完成实操。每章全部讲解小节都有对应任务，[随堂自测](../../labs/quiz.md)另提供每章两道基础选择题。

## 版本与勘误

本轮依据已保存并校验来源哈希的成书快照编写。扫描识别错误与原书疑点分开记录；未确认的参数和公式不用于给出唯一标准答案。Photoshop 2020、Audition、Premiere、Animate、Maya、Dreamweaver 等操作按教材版本理解，不据旧版截图推断当前软件或浏览器支持。
