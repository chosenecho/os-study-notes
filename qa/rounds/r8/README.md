# R8：笔记润色与校对

日期：2026-11-03。按 `humanizer-zh` 处理两门课十二章笔记、两份课程导读及两份共用速查表，共 16 个 Markdown 源文件。

## 本轮改动

- 收紧冗长句，减少重复解释、堆叠比喻和“钉死”“吊打”“硬核”等措辞。保留 `counter++`、读者—写者自习室、分页地址转换等有助于理解的实例。
- 删除或收敛“每年必见”“头号必考”“稳拿”等未经出处支持的考试频次和得分承诺；有明确卷次、题号的例题仍保留来源与自编标记。
- 区分教材模型与具体实现的适用范围，涉及 TLB 缺失与缺页、流水线延迟与吞吐率、C 类型转换、DMA 并行及 Cache 一致性等。
- 统一两份导读的语气和复习表头，纠正操作系统导读将中断响应列入第一章的指向，明确进程与线程的角色。
- 更新术语表中 FAT、ISA、DMA、SRAM、CISC 的说明，并在易错点清单中补入单总线节拍约束。
