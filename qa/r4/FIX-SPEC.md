## 1. 硬结构约束（hooks.py 依赖；破了站点就坏）

- 第 1 行必须是 `# 第 N 章 标题`。
- h2 必须写成 `## N 标题` 且 1..K 连续；h3 必须 `### N.M 标题`，N 等于所属 h2 编号；**不许 h4**。
- 习题节标题必须含「教材本章习题」；新增自编题节用 `## N 自编客观题（补充）`（fix-meta 会把它加进 hooks 的习题节正则，答案即自动折叠）。

- 单选选项写成一行：`A. …　B. …　C. …　D. …`（全角空格分隔）；填空占位用 ASCII `___`。
- 表格分隔行一律 `| --- | --- |`；图片 `![图N-M 标题](图/xxx.svg)` + 空行 + `*图N-M 标题*`。
- 散文不许出现 ASCII 双引号 `"`；全角标点后不许接空格。
- **不要动** R3 刚统一的骨架：`> 依据：` 块、`## 复习导航：大纲要求与笔记位置`、`## 本章学习目标`、`## N 考核要求`、`## N 闭卷复习与跨章联系（补充）`（章末内容按 §2.5 重写，标题不动）。
