## 术语与写法约定

| 概念 | 本课用词 | 首次出现 | 与另一门课的关系 |
|---|---|---|---|
| 主存 / 内存 | 主存（内存条、内存控制器等固定硬件名保留「内存」） | 主存（内存） | 操作系统概论以「内存」为主词 |
| 处理机 / 处理器 / CPU | 处理器 / CPU | 处理器 | 操作系统概论用处理机/处理器 |
| 页框 / 页帧 | 页框 | 页框（页帧） | 两书都用页框 |
| 外存 / 辅存 | 辅存 | 辅存（外存） | 操作系统概论用外存 |
| Cache / 高速缓存 | Cache | Cache（高速缓存） | 操作系统概论多用高速缓存 |
| 快表 | 快表 | 快表（TLB） | 两书一致 |
| 通道 | 内存通道 / 存储通道 | — | 操作系统概论的「通道」指 I/O 通道 |
| 有效访存时间 | AMAT | 有效访存时间（AMAT） | 操作系统概论称 EAT |

写法约定：
- 容量按 1024 进位：`1 KB = 1024 B`，`1 MB = 1024 KB`；全书只用 KB/MB/GB，不混用 KiB/MiB。
- 进制：散文用 `…H` / `…B` 后缀；`0x` 只出现在 C 代码里。
- 数字：千分位用半角空格（`5 000`）；范围用 `–`（如 `1.1–1.2`）；散文转折才用 `—`。
- 中英文之间加半角空格；中文引述用 `“”`；同义别名用全角括号（如 `外设（I/O 设备）`）。
- 表格分隔行统一 `| --- | --- |`；并列要点用列表，对照/数值用表格，定义用加粗术语 + 短段。
- 互连与存储章节里的 PCIe、QPI、DDR 等例子采用教材时代的规格，用于理解教材例题的计算口径，不能当作今天的产品参数。

## 建议用法

初学按章节顺序读最省力。第 1 章先给系统全貌，第 2 章讲数据怎么编码和运算，第 3 章用指令描述机器操作，第 4 章拆开 CPU 的实现，第 5、6 章说明存储和 I/O 如何配合执行。数据通路与电路部分要对照教材原图，确认各部件究竟怎么连。

各章熟悉之后，可以集中攻计算专题：性能评价、补码与标志、IEEE 编码、寻址与分支、流水线、芯片扩展、Cache、虚实地址转换，以及磁盘与 I/O 开销。动笔前先把位宽、编址单位、时延定义和初始条件写清楚，形式相近而适用条件不同的公式才不会混。

每章末尾的教材本章习题可以直接拿来检验：先做概念题查漏，再做计算题练手。整理错题时别只抄答案，把当时错在哪个条件判断、用了哪个公式、单位怎么换算一并记下来；能用反例说明自己原来错在哪，才算真的懂了。
