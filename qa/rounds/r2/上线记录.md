## 4. 部署期间发现并修正的问题

**`_headers` 不是「后者覆盖前者」，而是把匹配规则的 Cache-Control 拼接起来。**
第一版修复用 `/assets/* immutable` + `/assets/interactions.js 300`，线上实际返回：

```
Cache-Control: public, max-age=31536000, immutable, public, max-age=300, must-revalidate
```

`katex.min.js` 同样被拼成 `max-age=31536000, immutable, ..., max-age=86400`。浏览器对重复 `max-age` 的解析不可预期，而且一旦按 immutable 处理，后续对 `interactions.js` 的修复就送不到回访用户——正是这条规则想避免的事。

**改法**：拆成互不重叠的叶子规则（`/assets/*` 通配删除），见 `站点/src/_headers`；重新部署后每个路径只剩一个 Cache-Control，已逐条验证。
