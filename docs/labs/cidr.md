# CIDR 地址块与路由

给定一个十进制 IPv4 地址及前缀长度，先预测地址块起点，再核对地址范围、掩码和可选路由表。

## 模型约定

32 位 IPv4 地址按网络前缀与剩余位划分，前缀范围为 /0–/32。每个地址块包含 $2^{32-p}$ 个地址，p 为前缀位数。地址块范围与“可分配给主机的地址数”分别展示。

仅在 /0–/30 范围给出传统子网模型的主机数，即总数减去块起点和末地址；这不是对地址实际可用性、保留用途或分配政策的判断。/31、/32 只显示地址块信息，不套用减二公式。

路由输入最多 20 个前缀，必须写块起点，不附下一跳。实验只对目的地址做最长前缀选择；相同前缀的管理优先级、路由度量和多路径不在本模型中。

## 自编算例

输入 10.23.45.67/20：

1. 主机部分为 12 位，块大小为 $2^{12}=4096$ 个地址，掩码为 255.255.240.0。
2. 第三个八位组中每块跨度为 16；45 位于 32–47，故块起点为 **10.23.32.0**，末地址为 **10.23.47.255**。
3. 按传统保留首尾地址的模型，主机数为 4094，范围为 10.23.32.1–10.23.47.254。
4. 路由表含 0.0.0.0/0、10.0.0.0/8、10.23.32.0/20 时，三者都匹配目的地址；选择最长的 **10.23.32.0/20**。
