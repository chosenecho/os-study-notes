## 0. 一句话结论

**这个仓库乱的不是"文件多"，是"层"错了。**

真正该维护的东西只有 44 个文件、0.30 MB（`课程/` 30 + `站点/` 11 + 根 3）。剩下的 1.72 GB 全是本地资料，却和主干混在同一个根目录下，还各自带着看不见的版本控制 —— 所以 `git status` 只报一行 `?? esa-deploy/`，看起来"很干净"，实际上有四套 git 在同一个目录树里各管各的。

整理的主线就一句：**让主干只放文本源，让本地资料有一个明确的收纳规则，让临时实验离开仓库。**

## 2. 诊断：六个真问题

### P1 四套 git 互相不可见（结构性问题，最贵）

根 `.gitignore` 第 2、3 行分别剪枝 `资产/` 与 `归档/` 整棵子树，所以根 `git status` 看不见它们内部的状态。而这两棵子树里各有一个 `.git`：

- 你永远不知道 `资产/` 里挂了 3 个删除未提交；
- 你 `git add -A` 时不会误加（被忽略），但你也**不会收到任何提醒**；
- 三个内层仓库 6 个月只提交了 1 次 —— 版本控制形同虚设，只剩开销。

### P2 临时实验占了根目录，且既没跟踪也没忽略

`esa-deploy/` 37→39 个文件，29 个平铺在根：6 张截图（约 1 MB）、`site-dist.zip` + `site-dist.tar.gz`（1.7 MB，`站点/dist` 的完整副本）、`cfst/` 8 MB 第三方二进制、8 个一次性探针脚本。README 一个字没提。**下一个人打开仓库，第一个问题必然是"esa-deploy 是什么"。**

### P3 手写源、生成物、构建产物三层混居在 `站点/`

`站点/` 122 个文件里只有 11 个是手写的，但生成物（27 个，写进 `docs/` 里）和构建产物（79 个，`dist/`）就在同一层。后果不是"看着乱"，而是**忽略规则必须手工镜像代码行为**：`站点/.gitignore` 第 6-8 行逐条列了三个生成目录，而这三个正是 `hooks.py:39/40/64` 的三个 `mkdir` 目标 —— 加一门课就失配，生成物会被 `git add` 进仓库。

### P4 生成物会过期，但没有任何提示

`dist/` 是 10-31 21:36 的构建（后被并行会话于 10:57 重建）。只要改了 `课程/` 里的笔记，`dist/` 立刻落后，而本地预览看的是 `dist/` —— 你会以为改动没生效。

### P5 归档层：984 MB 里 507 MB 是压缩分卷和 2018 年的安装包

`ncre/` 一个科目目录 147 个文件 984 MB，其中 RAR/ZIP/EXE/MSI 共 521 MB；`二级 Python` 科目下塞着 2018 年的 python-3.4.3.msi 与 python-3.5.3.exe；`ncre/软件/` 目录名无任何语义。同时两门不同课程（04735 与 13170）混在一个 `数据库/` 里。

### P6 文档与现实脱节，其中一处是死链

README 16 处不符（逐条见 `report-核心.md §6`）。最硬的一处：`课程/计算机组成原理/README.md:42` 指向 `资产/旧版笔记备份_20261031/`，**该目录在磁盘上已不存在**，内容只剩在 `资产/.git` 对象库里（11,943 字节，已被现行三章笔记取代）。

## 4. 分阶段方案

> 阶段划分原则：**每个阶段结束时仓库都是可用状态**，可单独提交、单独回滚。
> 标 🤖 的阶段有脚本支持；标 ✍️ 的需要人工改文件（改动点已精确到行号）。

### T0 🤖 备份与基线（10 分钟，必须先做）

```powershell
powershell -File _整理\整理执行.ps1 -Phase T0 -Apply
```

1. 三个内层仓库各打一份 `git bundle`，落到 `Documents\_备份\git-bundle-20261101\`，并 `bundle verify` 逐个验过；

目标：让 `docs/` 变成 100% 派生目录，手写源搬到 `src/`。收益是**加课成本从"改 5 个文件"降到"改 3 个"**，且 `站点/.gitignore` 再也不用镜像代码行为。

#### T3.1 `站点/hooks.py` 改成表驱动

现状：`hooks.py:42-61` 与 `:63-73` 是两段几乎一样的循环，靠 5 个差异点（章数、输出目录、`co-` 前缀、是否复制图、是否改写 `<img>`）区分；两个 `next()` 都没有唯一性检查，放一个 `第1章_…_笔记 - 副本.md` 进去会静默取到不确定的那个。

#### T3.2 `mkdocs.yml` 加一行

`docs_dir: docs`（显式声明，别依赖默认推断）。

#### T3.4 CI 加一条防失配断言（可选但便宜）
