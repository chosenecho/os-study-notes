# 计算机组成原理

本课程以袁春风《计算机组成原理》（2016 年版）配套自学考试大纲的条目和能力层次作复习索引。各章提供独立撰写的机制讲解、计算模型与自编练习，不转载教材整套习题和附录答案。大纲版本用于定位，请另行核对报考机构的现行公告。

## 怎样复习

识记题先准确命名；领会题说明机制、条件与反例；应用题先列模型和单位，再逐步计算。每章导航表把大纲条目关联到讲解小节和练习题号，题后列出考点与解析。先独立作答，再展开答案核对。

计算中使用 KiB、MiB 表示 1024 进位容量，GB/s 等十进制带宽依题设换算；地址默认从 0 编号。编址单位、抢占规则、缓冲假设、缓存命中代价都应以题面为准，不推测未给出的条件。
