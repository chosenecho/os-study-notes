# 易错点清单

只收 12 章正文里已经写明的坑，按「现象 → 为什么错 → 正确做法」压缩成一行；出处给到课程与章，回原文看上下文。不新编。

| 现象 | 为什么错 | 正确做法 | 出处 |
|---|---|---|---|
| 周转时间从「开始时刻」算起 | 周转时间 = 完成 − 提交，中间等的那段也算 | 基准取提交时刻；9:00 开始、8:30 提交，先把 30 分钟等待算进去 | 操作系统概论 第3章 |
| 12 位地址说成能寻 4096 字节 | 模型机按字编址，一个地址单元是 16 位字 | 先问编址单位：4096 字 = 8192 字节 | 操作系统概论 第1章 |
| 把「不安全」当成「已经死锁」 | 不安全只是找不到保证完成的次序，系统还在跑 | 安全=有保证，不安全=没保证，已死锁=真的卡住 | 操作系统概论 第3章 |
| 把「忙则等待」与「让权等待」混成一件事 | 前者要求必须等，后者管的是怎么等 | 等的时候交出 CPU 才叫让权等待，`while S<=0` 忙等违反它 | 操作系统概论 第2章 |
| 一边想逻辑一边写 P/V | 动作顺序没定，锁的插入就没有依据 | 先写动作顺序，再把 P/V 按「谁等谁」插进去 | 操作系统概论 第2章 |
| FAT 与 i 结点说不清差别 | 两者都能让文件离散存放，差别只在链表存在哪里 | FAT 把下一簇号集中到全盘一张表，i 结点摊进每个文件的索引节点 | 操作系统概论 第5章 |
| LRU 命中后仍按访问时间重排队列 | 命中只刷新访问标记，不改变先进先出的位置关系 | 命中不换位置，缺页才动队列；先确认题目给的是 LRU 还是 FIFO | 操作系统概论 第4章 |
| 把补码当无符号数直接相乘 | 两种算法得到的机器数本来就可能不同 | 先符号扩展、按补码算法算，别指望结果自动正确 | 计算机组成原理 第2章 |
| 认为块越大越好 | 块变大会减少行数，冲突缺失反而盖过收益 | 块大小要在缺失损失与块数之间折中，不是单调变好 | 计算机组成原理 第5章 |
| 把解释执行理解成「先生成完整机器程序再运行」 | 解释程序是逐句取、逐句执行，不产出独立目标程序 | 解释器不生成完整机器程序，这是它与编译的区别 | 计算机组成原理 第1章 |
| 流水线时钟周期直接取最长一段的延时 | 没算流水线寄存器的建立与传输开销 | 最长段延时 + 寄存器开销，例：80 ps + 20 ps = 100 ps | 计算机组成原理 第4章 |
| 相对寻址拿本条指令首地址减目标地址 | 取指结束 PC 已自动加过指令长度，指向下一条 | 基准 PC 用取指后的值：两字节指令 +2，MIPS 指令 +4 | 计算机组成原理 第3章 |
| 把「数据区容量」当成 Cache 总容量 | 每行还要存有效位、标记、脏位与替换控制位 | 总位数 = 行数 ×（数据块位数 + 标记 + 有效位 + 脏位 + 替换位） | 计算机组成原理 第5章 |
| 用虚页号直接当页框号拼物理地址 | 二者编号体系不同，页表查出来的才是页框号 | 页框号替换虚页号，页内偏移原样保留；再按二进制重切查 Cache | 计算机组成原理 第5章 |
| 算 Cache 块号用元素字节数去除 | 块号 = 地址 ÷ 块大小，除数是每块字节数 | 32 B 块、4 B 元素，所以 $\lfloor j/8\rfloor$，不是 $\lfloor j/4\rfloor$ | 计算机组成原理 第5章 |
| 频率已按倍率给的（1333 M）还再乘一次 2 | DDR3-1333 的 1333 M 已是每秒传输次数 | 直接算 $8\ \text{B} \times 1333\ \text{M}$，三通道再乘 3 | 计算机组成原理 第6章 |
| 平均旋转等待时间算成转一整圈 | 扇区位置随机，平均落在半圈处 | $30/r$ 秒：7200 RPM 即约 4.17 ms，不是 8.33 ms | 计算机组成原理 第6章 |
| 把「断点」与「现场」混为一谈 | 断点只是返回位置 PC（+PSW），现场是通用寄存器数据 | 硬件存断点、服务程序软件存现场，两者分工不同 | 计算机组成原理 第4、6章 |
| 以为外部中断可在指令执行中途响应 | 指令算到一半的状态无处安放，回来接不上 | 外部中断只在两条指令交界处采样响应，DMA 才可插在周期边界 | 计算机组成原理 第6章 |
