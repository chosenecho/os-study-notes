# 术语与缩写表

两门课共用的一张速查表：读笔记遇到缩写先查这里，再回原章看上下文。「首现」指该缩写第一次出现的课程与章（OS = 操作系统概论，CO = 计算机组成原理），按首现章定位最快；同一缩写在两门课含义不同时写在备注里。

| 缩写 | 中文全称 | 英文全称 | 首现 | 备注 |
|---|---|---|---|---|
| PCB | 进程控制块 | Process Control Block | OS 第2章 | 进程存在的唯一标志，进程表就是 PCB 的集合 |
| PV | P 操作与 V 操作 | Passeren / Vrijgeven（荷兰语原词） | OS 第2章 | 写代码用 `wait(s)`、`signal(s)`，别把 P/V 当成英文缩写 |
| PIT | 可编程间隔定时器 | Programmable Interval Timer | OS 第2章 | 时钟中断的来源之一，时间片靠它计时 |
| RTC | 实时时钟 | Real-Time Clock | OS 第2章 | 掉电靠电池走时，管的是「现在几点」 |
| SDT | 系统设备表 | System Device Table | OS 第6章 | 全系统一张，每条指向一个 DCT |
| DCT | 设备控制表 | Device Control Table | OS 第6章 | 记录设备状态、等待队列与指向 COCT 的指针 |
| COCT | 控制器控制表 | Controller Control Table | OS 第6章 | 一个控制器一张，指向所接通道的 CHCT |
| CHCT | 通道控制表 | Channel Control Table | OS 第6章 | 通道型设备的入口，四级表格的最上层 |
| FAT | 文件分配表 | File Allocation Table | OS 第5章 | 链式分配的集中式实现：下一簇号存在全盘一张表里 |
| SPOOLing | 假脱机 | Simultaneous Peripheral Operations On-Line | OS 第6章 | 用磁盘上的输入井、输出井把独占设备改成共享 |
| TLB | 快表 | Translation Lookaside Buffer | OS 第4章 | 页表项的高速缓存，命中就不必再访存查页表 |
| LRU | 最近最少使用 | Least Recently Used | OS 第4章 | 淘汰最久未被访问的页；别与 LFU 的「次数」混淆 |
| LFU | 最不经常使用 | Least Frequently Used | OS 第4章 | 按访问次数淘汰，新页可能一直轮不到 |
| OPT | 最佳置换 | Optimal | OS 第4章 | 淘汰将来最久不用的页，理论最优、无法实现，只作对照 |
| EAT | 有效访问时间 | Effective Access Time | OS 第4章 | 本课的 `m` 是访存时间（纳秒级）；CO 的 AMAT 里 `m` 是缺失率，公式不可互搬 |
| AMAT | 平均访存时间 | Average Memory Access Time | CO 第5章 | 本课的 `m = 1 − h` 是缺失率（无单位），OS 的 EAT 里 `m` 是访存时间，公式不可互搬 |
| CPI | 每指令时钟周期数 | Cycles Per Instruction | CO 第1章 | 执行时间 = 指令条数 × CPI ÷ 主频 |
| MIPS | 每秒百万条指令 | Million Instructions Per Second | CO 第1章 | 只在同类程序间可比，不可跨指令集横比 |
| ISA | 指令集体系结构 | Instruction Set Architecture | CO 第1章 | 软硬件的分界面，编译器与 CPU 的合同 |
| DMA | 直接存储器访问 | Direct Memory Access | OS 第6章 | 成块搬运，只在开始与结束时打扰 CPU |
| RAID | 独立磁盘冗余阵列 | Redundant Array of Independent Disks | CO 第6章 | 教材用 RAID 0/1/5 讲容量、可靠性与写惩罚 |
| DRAM | 动态随机存取存储器 | Dynamic Random Access Memory | CO 第2章 | 靠电容存位、需定期刷新，主存主体 |
| SRAM | 静态随机存取存储器 | Static Random Access Memory | CO 第5章 | 快而贵、不用刷新，做 cache |
| CISC | 复杂指令集计算机 | Complex Instruction Set Computer | CO 第3章 | 指令多、长度不一，一条指令可干多件事 |
| RISC | 精简指令集计算机 | Reduced Instruction Set Computer | CO 第3章 | 定长指令、load/store 结构、寄存器多 |
| PC | 程序计数器 | Program Counter | OS 第1章 | 指向下一条要取的指令地址 |
| IR | 指令寄存器 | Instruction Register | OS 第1章 | 存放正在执行的那条指令 |
| PSW | 程序状态字 | Program Status Word | OS 第2章 | 中断与进程切换时要保存的现场之一 |
| ALU | 算术逻辑单元 | Arithmetic Logic Unit | CO 第1章 | 数据通路里真正做运算的部件 |
| IDT | 中断描述符表 | Interrupt Descriptor Table | OS 第2章 | 按中断号查中断服务程序入口 |
| BIOS | 基本输入输出系统 | Basic Input/Output System | 笔记未出现 | 保留备查 |
| PCI | 外设部件互连 | Peripheral Component Interconnect | CO 第6章 | 教材年代的总线实例，规格不能当今天的产品参数 |
| USB | 通用串行总线 | Universal Serial Bus | OS 第1章 | 即插即用的串行总线，作外设举例出现 |
| ASCII | 美国信息交换标准代码 | American Standard Code for Information Interchange | OS 第5章 | 7 位编码 128 个字符，第 8 位常作校验或扩展 |
| IEEE 754 | 二进制浮点数算术标准 | IEEE Standard for Floating-Point Arithmetic | CO 第2章 | 单精度 1+8+23、双精度 1+11+52，另有阶码 0 与 255 的特例 |
| GB 2312 | 信息交换用汉字编码字符集 | —（国标编号，无英文全称） | CO 第2章 | 区位码编码，与 ASCII 混排时按字节区分 |
| HT | 超线程 | Hyper-Threading | 笔记未出现 | 保留备查；它是 SMT 的一种商业实现名 |
| CRC | 循环冗余校验 | Cyclic Redundancy Check | CO 第2章 | 模 2 除法取余数，余数拼在数据后一起发送 |
| EPROM | 可擦除可编程只读存储器 | Erasable Programmable Read-Only Memory | CO 第5章 | 紫外光擦除，写入次数有限 |
| Flash | 闪存 | Flash Memory | CO 第5章 | 电擦除、按块写，U 盘与 SSD 的基础 |
| Cache | 高速缓存 | Cache Memory | OS 第4章 | 两书都讲，CO 的映射与缺失分析更细 |
| MMU | 存储管理单元 | Memory Management Unit | OS 第4章 | 硬件做逻辑地址到物理地址的转换 |
