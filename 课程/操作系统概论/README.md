## 考核层次

- **识记**：能独立给出定义、列出构成，并准确辨别名称。
- **领会**：能解释机制、比较差异，并根据条件跟踪算法过程。
- **简单应用**：能把给定规则用于明确场景，写出必要步骤。
- **综合应用**：能把多个知识点组合起来建模、计算、说明结论。

第二章信号量、第四章分页及二级分页、第五章目录与地址结构属于综合应用内容，需要结合具体条件建模和计算。第三章周转时间与银行家算法要求简单应用。页面置换和磁盘调度虽列为领会层次，也需要理解规则并跟踪执行过程。

## 建议学习顺序

初学时宜按教材章节顺序阅读，结合每章的大纲表确认要求。概念基本明确后，可集中练习 PV、进程调度、银行家算法、地址转换、页面置换、文件容量与磁盘调度，再用闭卷自测检查掌握情况，回到相应小节修正理解或计算步骤。

“进程读取文件”可以串联各章内容。进程通过系统调用请求读文件，文件系统依据路径定位文件和数据块，内存管理支持缓冲及地址映射，设备管理组织实际传输。如果数据尚未就绪，进程会阻塞等待；I/O 完成后，系统将其唤醒并放回就绪队列，再由调度程序决定何时执行。
