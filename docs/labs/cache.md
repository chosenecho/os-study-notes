输入行数、块大小与地址序列，查看直接映射的行号、标记、命中和替换。

## 模型约定

按字节编址，Cache 初始全无效；每次都是读访问，整块装入。不计预取、写策略和多级 Cache。

主存块号 = ⌊地址 ÷ 块大小⌋；行号 = 块号 mod 行数；标记 = ⌊块号 ÷ 行数⌋。命中要求该行有效且标记相同；块内偏移不会影响标记判断。

先观察 `0 4` 是否命中同一块，再观察 `0 64 0` 为什么会冲突。
