## 1 输入与输出设备 {#s1}

输入设备产生系统可接收的信息，输出设备把处理结果呈现或交付给外部。键盘、显示器、传感器和网络接口的速率、传输单位与实时要求不同。

设备不一定直接连接处理器内部数据通路，通常经接口、控制器和互连协作。设备自身速度与主机接口标称带宽也不能直接等同。

## 2 外部存储器 {#s2}

机械磁盘访问包含寻道、旋转及传输，SSD 由非易失存储与控制器组织，光盘等介质又有不同读写机制。容量、持续带宽、随机延迟、耐久性与可恢复性是不同指标。

自编机械模型：7200 rpm 每转约 8.333 ms，随机相位的平均旋转等待约 4.167 ms；给定寻道与传输时间后才能算访问总量。SSD 不包含机械旋转，不能把转速公式移植过去。

## 3 互连与总线 {#s3}

地址、数据和控制是总线模型中的三类信息。同步总线按共同节拍约定采样，异步握手以请求与应答协调；仲裁决定多个主控者争用时谁先使用共享资源。串行点到点链路与传统共享并行总线的拓扑不同。

自编模型：32 位数据宽、每周期一次数据传输、频率 50 MHz，理想数据带宽为 200 MB/s；若一次完整事务占 4 周期且只交付一个数据字，事务层有效值为 50 MB/s。

## 4 I/O 接口与寻址 {#s4}

接口寄存器常承担数据、状态和控制职责。统一编址把设备寄存器映射到内存地址空间，独立编址使用专用 I/O 空间及相应指令；实际访问仍应遵守设备副作用与顺序规则，不能把设备地址当普通可缓存 RAM 随意读写。

一次典型交互先检查或等待就绪，再按方向搬运数据，最后确认完成或错误。读状态是否清除某些位、写控制是否启动操作，都要由接口协议定义。

## 5 控制方式与开销 {#s5}

查询方式由 CPU 反复检测状态，中断方式在事件到来时转入服务，DMA 把批量搬运交给设备侧或专门引擎。中断优先级、屏蔽与嵌套策略影响响应顺序，响应中断不等于一定切换进程。

| 比较项 | 程序查询 | 中断控制 | DMA |
| --- | --- | --- | --- |
| 就绪通知 | CPU 反复读状态 | 事件引发中断 | 控制器按传送协议工作 |
| 常规模型中的数据搬运者 | CPU | CPU | DMA 控制器或设备 DMA 引擎 |
| CPU 的准备工作 | 设置命令和缓冲 | 设置命令、缓冲和中断 | 设置地址、长度、方向与描述符 |
| 等待期间 CPU | 查询占用执行机会 | 可执行其他任务 | 可执行其他任务 |
| 完成处理 | 查询发现完成 | 中断服务处理 | 常以完成中断通知 |
| 共享资源影响 | 指令与访存开销 | 服务程序和切换开销 | 总线或内存竞争及一致性维护 |

DMA 周期挪用使共享传输资源的部分周期交给 DMA，不保证 CPU 完全不停顿，也不要求整个传送阶段都停机。现代架构下的 DMA 还要处理设备可见地址、IOMMU 和 Cache 一致性；设备能访问物理资源，不表示可以无约束地绕过隔离。

自编开销模型：设备速率 10000 字/s，按每字一次中断、每次服务 5 μs 计，CPU 服务时间占比为 5%。若每 20 字一次 DMA 完成中断、每次 8 μs，则中断服务占比为 0.4%，但尚未计初始化、映射、同步与内存争用。

## 本章小结

- 接口选型既看峰值带宽，也看粒度、响应期限和完成开销。设备寄存器即便统一编址，也可能有副作用及顺序约束。
- 总线节拍上限由每次字节数与传输频率决定，事务交付率还要扣除地址、等待和其他规定周期；两种口径必须分开。
- 查询、中断与 DMA 的 CPU 负担应按题设计量。完成中断占比下降不证明初始化、同步及所有系统成本都已消失。

## 自编练习

**1. 为传感器与离线备份盘设计接口，为什么不能只比较最高带宽？机械盘的平均半转等待又有哪些假设？**

考点：第 1、2 节；层次：领会。

**答案：** 还要比较响应期限、数据粒度、随机延迟和可靠性。平均半转采用随机且均匀的到达相位等模型，不能描述 SSD，也不等于每次机械访问恰好等半转。

**2. 32 位、50 MHz 总线每事务用 4 周期传一个字，理想节拍带宽与该事务有效带宽各是多少？**

考点：第 3 节；层次：简单应用。

**答案：** 每字 32÷8=4 B，时钟周期 1/(50×10⁶)=20 ns；每周期一字的节拍上限为 4×50×10⁶=200 MB/s。每事务占 4×20=80 ns，只交付 4 B，故事务有效带宽为 4/(80×10⁻⁹)=50 MB/s。前提未包含其他仲裁和等待。

**3. 某设备把状态寄存器放在普通地址空间中，是否可以把读取它当作没有副作用、可任意重排的普通变量访问？**

考点：第 4 节；层次：领会。

**答案：** 不可以。统一编址只说明地址组织，设备访问仍需遵守缓存属性、顺序和副作用协议，例如读取清除状态位。

**4. 10000 字/s 的设备每字中断服务 5 μs，求服务占比；改为每 20 字一次、服务 8 μs 的 DMA 完成中断后，该占比是多少？是否等于全部 CPU 成本？**

考点：第 5 节；层次：简单应用、领会。

**答案：** 原占比 10000×5 μs=0.05，即 5%；新占比 500×8 μs=0.004，即 0.4%。这只计指定中断服务，还需考虑初始化、同步等开销。
