# 计算机组成原理

依据袁春风《计算机组成原理》（2016 年版）配套自学考试大纲整理。

## 章节与练习

| 章节 | 复习范围 | 自编练习 |
| --- | --- | --- |
| [第 1 章 计算机系统概述](chapter-01.md) | 硬件、软件、系统层次、程序执行、性能 | 4 题 |
| [第 2 章 数据的表示和运算](chapter-02.md) | 数制、整数、浮点、字符、端序、校验、算术运算 | 7 题 |
| [第 3 章 指令系统](chapter-03.md) | 指令格式、寻址、MIPS、机器级程序 | 4 题 |
| [第 4 章 中央处理器](chapter-04.md) | 数据通路、定时、控制器、流水线、异常与中断 | 6 题 |
| [第 5 章 存储器层次结构](chapter-05.md) | SRAM、DRAM、芯片扩展、Flash、Cache、虚拟存储 | 5 题 |
| [第 6 章 互连及输入输出组织](chapter-06.md) | 外设、磁盘、总线、I/O 接口、传送控制 | 4 题 |

容量单位：KiB、MiB 按 1024 进位；带宽按题设换算。地址默认从 0 编号，其他条件见各题。

## 复习路径与版本

先按目录阅读讲解，闭卷复述本章小结，再用自编练习核对过程；需要换一组题时进入[分章自测](../../labs/quiz.md)。计算题先保留自己的单位、条件与中间式，再展开解析。
