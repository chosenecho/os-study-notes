# qa：站点质量审计

- `scripts/` 是可复现的审计脚本（`verify-fixes.mjs` 37 项断言、`lead-links.mjs` 站内链接、逐设备报告生成），`reports/` 是当轮留下的报告。
- `artifacts/` 是截图与原始 JSON（约 25 MB），已被 `.gitignore` 忽略，只在本地保留。
- `r2/`、`r3/`、`r4/` 是各轮审计的本地证据快照（截图、原始 JSON、中间产物，合计 170+ MB），同样**不入库**，换机器就没了。
- `r4/_scratch/` 是施工临时目录；需要复现某条证据时重跑 `scripts/` 里的脚本，不要指望快照还在。
- 要长期留存的只有 `qa/*.md` 报告与 `scripts/`：写结论时把数字落到报告里，别只留在快照里。
