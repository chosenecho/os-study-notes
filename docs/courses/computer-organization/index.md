## 术语与写法约定

| 概念 | 本课用词 | 首次出现 | 与另一门课的关系 |
|---|---|---|---|
| 主存 / 内存 | 主存（内存条、内存控制器等固定硬件名保留「内存」） | 主存（内存） | 操作系统概论以「内存」为主词 |
| 处理机 / 处理器 / CPU | 处理器 / CPU | 处理器 | 操作系统概论用处理机/处理器 |
| 页框 / 页帧 | 页框 | 页框（页帧） | 两书都用页框 |
| 外存 / 辅存 | 辅存 | 辅存（外存） | 操作系统概论用外存 |
| Cache / 高速缓存 | Cache | Cache（高速缓存） | 操作系统概论多用高速缓存 |
| 快表 | 快表 | 快表（TLB） | 两书一致 |
| 通道 | 内存通道 / 存储通道 | — | 操作系统概论的「通道」指 I/O 通道 |
| 平均访存时间 | AMAT | 平均访存时间（AMAT） | 本课第 5 章重点分析 Cache 命中与缺失；操作系统第 4 章用 EAT 分析缺页，先核对开销定义再套公式 |

写法约定：
- 存储容量默认按 1024 进位：`1 KB = 1024 B`，`1 MB = 1024 KB`。总线、磁盘和 I/O 速率题中的 M、G 可能按十进制计，须以题目或本题说明为准；计算时先统一单位。
- 进制：散文用 `…H` / `…B` 后缀；`0x` 只出现在 C 代码里。
- 数字：千分位用半角空格（`5 000`）；范围用 `–`（如 `1.1–1.2`）；散文转折才用 `—`。
- 中英文之间加半角空格；中文引述用 `“”`；同义别名用全角括号（如 `外设（I/O 设备）`）。
- 表格分隔行统一 `| --- | --- |`；并列要点用列表，对照/数值用表格，定义用加粗术语 + 短段。
- 互连与存储章节里的 PCIe、QPI、DDR 等例子采用教材时代的规格，用于理解教材例题的计算口径，不能当作今天的产品参数。

## 建议用法

初学时按章节顺序阅读：第 1 章了解系统组成，第 2 章学习数据表示与运算，第 3 章分析指令，第 4 章学习 CPU 实现，第 5、6 章学习存储与 I/O。数据通路和电路分析应对照教材原图确认连接关系。

熟悉各章后，可按专题练习性能评价、补码与标志、IEEE 编码、寻址与分支、流水线、芯片扩展、Cache、虚实地址转换、磁盘和 I/O 开销。计算前先写明位宽、编址单位、时延定义和初始条件，再选用公式。

章末教材习题可先做概念题，再做计算题。整理错题时，除答案外，还应记录误判的条件、公式选择和单位换算；必要时用反例检验原来的判断。

## 各章复习主线

| 章 | 复习主线 | 重点辨析与计算 |
| --- | --- | --- |
| 1 | 存储程序、翻译与装入、取指执行、CPU 时间 | $\text{IC} \times \text{CPI} \times T$，注意主频与时钟周期的换算 |
| 2 | 位串本身没有含义，含义由编码规则与解读方式决定 | IEEE 754 编解码、大端小端、海明校验位、标志 OF/CF |
| 3 | 指令如何表示操作、操作数和控制流 | 扩展操作码条数、相对寻址的 $\text{PC} + \text{指令长}$ |
| 4 | 数据通路、指令重叠执行与异常处理 | 流水线 $(k+n-1+s)\tau$、Load-Use 停 1 拍 |
| 5 | 局部性、存储层次、Cache 与虚拟存储 | Cache 地址切分与总位数、页表查出来的物理地址再切 Cache |
| 6 | 用总线连起来 → 用接口过渡 → 用中断/DMA 少占 CPU | 磁盘 $30/r$ 旋转等待、DDR/QPI/PCIe 三种带宽口径 |
