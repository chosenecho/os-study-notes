## 本章学习目标

指令系统规定计算机能够执行哪些操作，以及如何描述操作数和执行顺序。本章要求识记指令格式、操作类型、寻址方式和指令系统风格，并理解有效地址、操作码编码、RISC/CISC与MIPS实例。在分析程序时，需要根据指令确定操作数来源、运算过程、结果位置和后继指令地址。

## 1 指令格式设计（1，识记、领会）

一条指令要完成操作，需要确定操作类型、源操作数、结果位置和后继指令地址。这些信息可以写在指令字段中，也可以由机器约定隐含给出。指令的基本格式由操作码和地址字段组成，其中操作码说明操作类型，地址字段可以表示存储地址、寄存器编号或立即数。顺序执行时，后继指令地址通常由PC的更新得到，无须单独设置地址字段。

| 显式地址数 | 常见语义示意 | 隐含内容 |
| --- | --- | --- |
| 三地址 | A₃←A₁ op A₂ | PC提供后继地址 |
| 二地址 | A₁←A₁ op A₂ | 其中一个源也作为目的 |
| 一地址 | AC←AC op M[A] | 累加器AC |
| 零地址 | 对栈顶两个元素运算并压回结果 | 操作数栈及栈顶位置 |

上述为常见约定，具体字段顺序以题目为准。地址数少可缩短指令，但可能增加中间传送或访存次数。指令格式设计需权衡指令长度、地址空间、操作种类、译码复杂度、代码密度和执行效率。

指令字长、机器字长、存储字长不是同一个概念。按字节编址时，一条32位定长指令占4字节，顺序PC通常增加4。

## 2 指令系统设计（2，识记、领会）

### 2.1 操作数与寻址

操作数可能是地址、整数、浮点数、字符或逻辑位串。设A为指令地址字段，R为寄存器，M[x]为地址x的存储内容，EA为有效地址：

| 方式 | 操作数/EA | 典型用途 |
| --- | --- | --- |
| 立即 | 操作数就是A，无须求操作数的主存地址 | 常数 |
| 直接 | EA=A，操作数=M[A] | 固定存储位置 |
| 间接 | EA=M[A]，操作数=M[EA] | 指针 |
| 寄存器 | 操作数=R[r] | 高频运算 |
| 寄存器间接 | EA=R[r] | 指针指向的数据 |
| 变址 | EA=A+R[index] | 数组元素 |
| 基址 | EA=R[base]+位移 | 段内/对象内数据 |
| 相对 | EA=指定基准PC+位移 | 分支、位置相关代码 |

变址与基址的加法形式相近，但寄存器在程序中的用途不同。相对寻址必须核对PC是当前指令地址还是下一条指令地址，以及位移是否需乘字长。

例：A=100，R=20，M[100]=300，M[300]=9。立即数为100；直接方式操作数300；间接方式操作数9；基址加位移的EA为120。地址120本身不是该处数据。

### 2.2 操作类型与控制流

传送指令搬运数据；算术指令加减乘除；逻辑指令按位运算；移位指令改变位位置；比较/条件分支根据状态或寄存器比较结果选择后继；无条件跳转直接改变PC。

过程调用会改变执行顺序，同时保存返回地址，使被调用过程结束后能够继续执行原程序。返回指令据此恢复执行位置。硬件中断也会转入另一段程序，但它由事件触发，无须程序显式执行调用指令，恢复时通常还涉及处理器状态。

条件分支如何解释比较结果，取决于操作数的数据类型。无符号比较可以利用减法产生的进位或借位信息；有符号比较则需要结合SF与OF，因为溢出可能使结果的符号位失去通常的大小含义。第2章中的标志位因此成为控制程序执行顺序的依据。

### 2.3 操作码编码

定长操作码的译码规则简单，k位最多编码2ᵏ种操作。扩展操作码利用地址字段较少的指令，延长操作码以容纳更多操作；短码不能成为另一条有效操作码的前缀而造成歧义。

例：16位指令，每地址字段4位；若三地址格式有4位操作码，分配15种三地址操作，保留一个前缀扩展，那么二地址操作码可用8位，其中该扩展前缀下有16个二地址编码。若其中再保留1个，则可分配15种二地址操作并继续扩展。不能把各长度编码数不加限制地相加。

定长指令字与定长操作码是不同维度：指令总长固定时，仍然可以采用扩展操作码。

### 2.4 指令系统风格

累加器型用隐含AC；栈型用隐含栈顶；通用寄存器型允许显式指定寄存器；Load/Store型只让装入、存储指令访问数据存储器，算术逻辑运算在寄存器之间完成。

| 比较 | RISC典型特征 | CISC典型特征 |
| --- | --- | --- |
| 指令设计 | 常用简单操作，格式规整 | 功能与格式较丰富 |
| 寻址 | 方式较少 | 方式较多 |
| 数据访存 | 常采用Load/Store | 可允许运算指令访问内存 |
| 流水线实现 | 较便于规整译码和分段 | 需要处理更多复杂情况 |

这些是设计倾向，不能推断RISC每条指令都只用一个时钟，或CISC一定更慢。

## 3 MIPS 指令集实例（3，领会）

教材以32位MIPS为例：32个通用寄存器，寄存器字段5位；指令长32位；0号寄存器读值为0。`R[x]`表示寄存器x的内容。

| 类型 | 字段长度 | 典型指令 |
| --- | --- | --- |
| R型 | op6、rs5、rt5、rd5、shamt5、funct6 | add、sub等 |
| I型 | op6、rs5、rt5、imm16 | addi、lw、sw、beq等 |
| J型 | op6、目标字段26 | j、jal |

`add $t0,$t1,$t2`：R[t0]←R[t1]+R[t2]。

`lw $t0,12($s0)`：EA=R[s0]+SignExt(12)，从EA装入一个字。`sw`把寄存器值写到EA。立即数字段是字节偏移，数组int元素若4字节，第i个元素偏移4i。

`addi`等需符号扩展；`andi/ori`的立即数采用零扩展，不能把所有16位立即数都统一符号扩展。

条件分支目标=PC+4+(SignExt(imm16)<<2)。若当前PC=1000H、imm=3，则目标=1010H。J型伪直接跳转将PC+4的高4位、26位字段、低2位00拼接，不能把26位字段直接当完整字节地址。具体延迟槽语义按教材例题或题设处理。

## 4 程序的机器级表示（4，领会）

高级语言选择结构用比较和条件分支跳过某代码块；循环用条件判断、循环体、更新和回跳构成。数组访问需要“首地址+下标×元素大小”，取元素还要解引用该地址。

例如，`if (a==b) c=d+e; else c=d-e;`可以通过比较a、b，并在不相等时跳转到else分支实现。两者相等时执行加法，随后无条件跳过else部分；不相等时执行减法，最后在共同的后继位置继续运行。汇编中的分支条件可能采用源程序条件的反向形式，其含义需要结合跳转目标判断。

循环的执行次数由循环变量初值、条件检测位置、更新量和退出分支共同决定。机器代码通常不保留源程序的变量名与缩进，因此需要根据寄存器和存储地址追踪变量，并沿分支目标还原循环结构。条件在循环体之前还是之后检测，也会影响循环体是否至少执行一次。
