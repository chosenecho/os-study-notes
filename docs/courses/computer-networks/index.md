# 计算机网络技术

本课程依据张海霞主编《计算机网络技术》（机械工业出版社，2016 年版）及配套自学考试大纲，课程代码 02141。九章依次从通信基础走到协议、互联、应用、管理与安全。内容采用本项目独立组织的讲解、自编任务和解析；能力层次用于复习定位，不代表现行考试公告。

## 章节与练习

| 章节 | 复习范围 | 自编练习 |
| --- | --- | --- |
| [第 1 章 计算机网络技术概论](chapter-01.md) | 网络形成、分类与拓扑、性能指标、标准组织 | 6 题 |
| [第 2 章 数据通信基础](chapter-02.md) | 传输与信道、调制与编码、复用、差错控制、交换 | 9 题 |
| [第 3 章 网络协议和体系结构](chapter-03.md) | OSI 与 TCP/IP、UDP、TCP 连接与窗口 | 7 题 |
| [第 4 章 局域网技术](chapter-04.md) | 以太网、交换学习、VLAN、无线局域网 | 7 题 |
| [第 5 章 网络互联技术](chapter-05.md) | IPv4、子网与 CIDR、路由、辅助协议、IPv6 | 8 题 |
| [第 6 章 网络应用技术](chapter-06.md) | DNS、FTP、邮件、HTTP、状态管理、HTML、电商 | 8 题 |
| [第 7 章 网络管理技术](chapter-07.md) | 管理架构、五类功能、SNMP、管理工具 | 7 题 |
| [第 8 章 网络操作系统](chapter-08.md) | 操作系统分类、网络服务、账户与域管理 | 6 题 |

## 怎样复习

先读导航表确认大纲范围，再用自己的话解释机制，最后独立完成练习并展开解析。应用题先写模型和单位，子网题区分地址总数与主机数，协议题区分首部、状态与交互方向。各章全部小节都有对应练习，随堂自测另提供每章两道基础判断。

## 版本与勘误

资料取自项目已校验的成书快照。书中明确校注的 A 类地址最高位、子网地址及 LDAPv3 等已在相应处处理；尚待核实的公式不作出题依据。Server 2008 操作及部分协议轨迹限定在教材环境，不用旧版产品描述推断当前部署与安全配置。
