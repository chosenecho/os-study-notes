## 本章学习目标

外部设备通过互连结构和I/O接口与CPU、主存交换信息。本章先介绍设备及其性能指标，再说明数据如何在系统中传输，以及CPU如何控制传输过程。计算内容包括磁盘访问时间、总线带宽和CPU的I/O开销；I/O接口、中断响应与处理、DMA是理解传输机制的重点。

## 1 输入和输出设备（1，领会）

键盘经按键扫描、编码、消抖，把按键动作变成信息。鼠标把位移与按键事件编码。打印机把字符或图像输出到纸面。显示器把显示数据变成像素图像。共同之处是完成物理量或用户动作与数字信息的转换，再经接口按约定交换数据和状态。

显示分辨率决定像素数，色深决定每像素位数；一帧最低数据量≈水平像素×垂直像素×色深/8，不含其他缓冲和协议开销。例：1920×1080、24位色约6,220,800 B/帧。打印机常看dpi和打印速度等指标，不能把dpi与屏幕的像素总数混为一谈。

## 2 外部存储器（2，领会）

磁盘把盘面划分为磁道，再把磁道划分为扇区。不同盘面上半径相同的磁道构成柱面。扇区除用户数据外，还包含标识、同步和校验信息，所以格式化后的可用容量小于原始记录容量。

理想均匀模型：容量=有效盘面数×每面磁道数×每道扇区数×每扇区字节数。现代实际布局可能不同，计算按题设。

访问时间≈寻道时间+旋转等待+传输时间+其他控制开销。转速r转/分，一圈60/r秒，随机位置平均旋转等待30/r秒。连续传输时间=数据量/传输率。

例：7200 rpm平均旋转等待4.167 ms。寻道8 ms，读64 KiB，传输率128 MiB/s，则传输0.488 ms，总约12.655 ms，未计控制器与排队开销。随机小读中，寻道和等待可能占主导。

单个磁盘的容量、访问速度和故障风险都受设备本身限制。RAID把多个磁盘组织成阵列，用条带化、镜像或校验等方式改善其中部分指标。不同级别采用的机制不同，性能与容错能力也有差别。

| RAID | 原理 | 要点 |
| --- | --- | --- |
| RAID 0 | 数据条带分布 | 提高并行能力，没有冗余保护 |
| RAID 1 | 镜像 | 保存副本，容量利用率下降 |
| RAID 5 | 分布式奇偶校验 | 常见同容量N盘可用约(N−1)盘，能容忍一盘故障 |

RAID通过多盘组织改善性能或可用性，效果取决于级别、访问类型和控制器。冗余不等于独立备份。

U盘和SSD通常采用Flash，无机械寻道、非易失；SSD控制器负责地址映射、纠错、磨损均衡等。随机写和擦除行为与机械磁盘不同，也不同于可随意覆盖的主存。

## 3 外设、CPU 和主存互连（3，识记、领会、简单应用）

总线是多个部件共享的一组传输通路。主控设备发起事务，从设备响应，主控身份可以随事务改变。内部总线连接处理器内部的部件，系统总线、存储器总线和I/O总线则负责不同范围的互连。

地址信息指出对象，数据信息承载内容，控制信息规定读写、时序、应答等。总线宽度一般指一次可并行传输的数据位数，寻址能力则取决于地址位数及编址单位。串行链路在每条通路上逐位发送，多条lane可以并行聚合，不能因为“串行”就推断它必然慢。

同步总线用统一时钟约定时序，异步总线靠请求/应答等握手协调。突发传输把多个数据连续发送，省去每个数据重复付出的地址和仲裁开销。

### 3.1 带宽计算

并行峰值带宽=每次有效数据位数/8×每秒传输次数×通道数。若每周期传q次，传输率=f×q；若已给MT/s，不再乘q。实际有效带宽还受仲裁、地址、握手及空闲周期影响。

例：64位、200 MHz、每周期4次，峰值为64/8×200×10⁶×4=6.4 GB/s。DDR3-1333的单个64位通道按1333 MT/s算约10.664 GB/s，三通道约31.992 GB/s。

教材的前端总线FSB连接CPU与传统桥接结构，存储器总线服务内存通路，QPI则是点到点互连。计算QPI时，先确定有效数据位与控制/校验开销，再确定是单向还是双向，不能拿全部物理位宽当有效载荷。

串行有效带宽=每lane位速率×编码效率×lane数/8。教材PCIe 1.0为2.5 Gb/s、8b/10b，单向每lane=2.5×0.8/8=0.25 GB/s，x16单向4 GB/s、双向合计8 GB/s。回答时必须标清单向还是双向合计；这里的编码效率也不能直接套用到其他代际。

## 4 I/O 接口（4，识记、领会）

接口负责匹配CPU与外设在速度、数据格式、时序、电平和工作方式上的差异。它提供设备选择、缓冲、控制、状态报告、错误检测以及中断/DMA支持等功能。CPU通常经接口访问外设，不直接控制设备的全部物理细节。

| 寄存器/结构 | 用途 |
| --- | --- |
| 数据缓冲寄存器 | 临时保存输入或输出数据 |
| 状态寄存器 | 就绪、忙、错误、中断请求等状态 |
| 控制/命令寄存器 | 指定启动、停止、模式等操作 |
| 内部接口 | 与系统总线/CPU侧连接 |
| 外部接口 | 与具体设备连接 |

I/O端口通常指接口中可由CPU访问的寄存器或其地址。一个接口可包含多个端口，端口不一定是机箱上的物理插口。

独立编址为I/O另设地址空间，常用专门I/O指令；统一编址把I/O寄存器映射入存储地址空间，可用访存指令访问，但会占用该空间的一部分。统一编址不意味着设备寄存器就是普通RAM，其访问可能有副作用。

## 5 I/O 数据传送控制方式（5，领会、简单应用）

### 5.1 查询方式

查询方式由CPU主动检查设备状态。CPU发出命令后读取状态寄存器；设备尚未就绪，就继续等待或稍后再次查询。设备就绪后，CPU通过数据端口搬运数据，并检查传输是否结束。这种方式实现简单，但连续轮询会让CPU一直忙等。

周期轮询开销比例=每秒查询次数×每次查询周期数/CPU频率，还要加实际搬运等成本。若CPU连续忙等，不能只算少量查询指令而忽略整个等待时间。

例：1 GHz CPU，每秒轮询10000次，每次100周期，占0.1%；这是周期查询的检查成本，不包含设备传输和忙等。

### 5.2 中断方式

为减少反复查询状态的开销，可以由设备在就绪或发生事件时提出中断请求。CPU启动设备后继续执行其他程序；收到请求并满足响应条件，才转入相应的中断服务程序。这种方式下，通知时机由设备决定，数据搬运仍由CPU执行指令完成。

本课程外部可屏蔽中断响应的常见条件：有请求、允许中断、指令执行到可响应边界；还需请求未被相应屏蔽等条件。不可屏蔽中断需另行讨论。

响应与处理步骤：

1. 设备提出请求，控制器判定优先级并向CPU报告。
2. CPU到可响应点，保存必要的断点与状态，转入入口，按体系结构规定控制中断允许状态。
3. 通过软件查询或向量机制确定服务程序。
4. 服务程序保护将要改动的现场，处理设备与数据，按需要确认或清除请求。
5. 恢复现场、执行中断返回，恢复正常程序。

中断处理中的保存工作由硬件和软件共同完成。断点保护保存返回位置；现场保护还要涉及通用寄存器、状态等，以免服务程序改动被中断程序仍需使用的内容。硬件保存哪些状态、软件再补充保护哪些，由体系结构和服务程序的约定决定。中断向量提供的是定位服务程序入口的信息，与设备传输的业务数据用途不同。

中断允许触发器控制CPU是否接受可屏蔽请求。服务程序若要允许更高优先级的中断嵌套，通常先保护现场、设置适当的屏蔽状态，然后再开放中断，以免嵌套处理破坏尚未保存的信息。中断优先级用于确定多个请求的选择顺序，屏蔽字用于限制当前允许进入的请求，两者分别控制不同环节。

中断与子程序调用都可能保存返回地址，但调用由程序中的显式指令发起，中断则由异步事件发起。中断返回时可能还要恢复状态。中断与异常的同步/异步区别见第4章。

中断开销比例=每秒中断次数×每次服务周期数/CPU频率。若每次传d字节、设备速率v字节/秒，中断次数≈v/d。每次开销需明确是否已含进入、退出、保护恢复和搬运。

例：每秒传1 MiB，每4 B中断一次，每次200周期，CPU 1 GHz，则262144次/s，开销52,428,800周期/s，约5.24%。

### 5.3 DMA方式

DMA适合高速设备与主存之间的成块传输。CPU设置主存起始地址、传输方向、计数等参数。DMA控制器获得所需的总线使用权后直接搬运，并更新地址和计数。传输完成或出错后，DMA控制器再通知CPU，常用中断方式。

DMA控制器通常包含地址寄存器、计数器、控制/状态寄存器及数据缓冲等，用于记录传输位置、剩余数量和设备状态。CPU负责初始化与完成处理，传输过程中的数据则无须逐字经过CPU寄存器。DMA仍会占用主存带宽，可能使CPU等待。有 Cache 的系统还要处理数据一致性，具体见 5.4。

常见组织包括停止CPU访存一段时间做突发传输、周期挪用，以及在CPU不使用总线时交替访问。要区分“CPU执行管理指令的开销”与“争用总线导致的等待”。

DMA的CPU管理开销比例≈每秒块数×每块初始化及完成处理周期/频率。若1 MiB/s按4 KiB一块，每块CPU开销1000周期，CPU 1 GHz：256块/s，开销0.0256%，另有总线争用等代价未计。

| 方式 | 谁实际搬数据 | CPU何时介入 | 主要代价 |
| --- | --- | --- | --- |
| 查询 | CPU指令 | 反复查状态并搬运 | 轮询或忙等 |
| 中断 | CPU指令 | 事件发生后服务 | 频繁进入退出与搬运 |
| DMA | DMA控制器 | 配置及完成处理等 | 管理、总线竞争等 |

### 5.4 现代架构下的 DMA 与 Cache 一致性

教材讲 DMA 的默认布景是单核、单总线：DMA 抢到总线，CPU 就停。今天这套图景已经不成立，但它仍是考试的计算口径，所以两件事要分开记——**算题按教材模型，理解要按现代架构**。

现代架构改了什么。CPU 与内存控制器之间有片上互连网络，外设经 PCIe 与根复合体接入，DMA 引擎走相对独立的数据通路。CPU 绝大多数访存命中 L1/L2，根本不碰主存；DMA 搬运时两者可以真正并行，只在争抢主存通道带宽的那一瞬有纳秒级仲裁等待，不再是「总线被抢走、CPU 彻底停摆」。

真正的麻烦落在 Cache 上。DMA 绕过 CPU 直接读写主存，于是有两种翻车方式：

| 场景 | 危险 | 后果 |
|---|---|---|
| DMA 读主存送往设备（发网包、写盘） | Cache 里还留着该地址的**脏行**，尚未写回主存 | DMA 读到旧数据，设备收到过期内容 |
| DMA 写主存（收网包、读盘） | 主存已更新，Cache 里仍是**旧副本** | CPU 随后读到陈旧数据，看不到新到的内容 |

解法分两条路：

- **硬件维护一致性**：x86 的内存控制器与 CPU Cache 之间有监听/目录机制，DMA 触碰某地址时会把对应 Cache 行失效或先要求回写，硬件替软件兜住，驱动不必操心。
- **软件维护一致性**：多数嵌入式 ARM 平台没有硬件监听，驱动必须在 DMA 前后显式操作——设备往内存写之前先让对应 Cache 行失效（invalidate），免得 CPU 的旧副本压在内存之上；内存往设备发之前先把脏行刷回（clean/flush），免得 DMA 读到旧值。Linux 里对应 `dma_sync_single_for_device` 与 `dma_sync_single_for_cpu` 这一对接口。

顺带把两门课最容易打结的地方一次拆开：

| 比较 | 操作系统的「进程阻塞」 | 计组的「DMA 周期挪用」 |
|---|---|---|
| 发生在哪一层 | 操作系统软件：内核把进程状态改为阻塞、挂入等待队列、切换栈与页表 | 硬件电路：DMA 控制器向总线仲裁器申请使用权 |
| 时间尺度 | 微秒到毫秒级（切换本身是微秒量级，等设备完成则可能更久） | 纳秒级（让出单个存储周期或一小段突发） |
| 此时 CPU 在干什么 | 主动转去运行另一个就绪进程，CPU 没闲着 | 被动停一个或几个存储周期，随后继续执行原指令 |
| 由谁发起 | 进程执行系统调用后条件未满足，或等待的事件尚未发生 | 外设控制器或 DMA 引擎发起总线请求 |
| 如何恢复 | 事件完成后唤醒进程，重新进入就绪队列，等调度程序选中 | 总线释放后 CPU 自动继续取指，不需要调度介入 |
| 程序能否察觉 | 程序员可见：涉及状态、队列、调度策略 | 对程序透明：指令流上看不出被打断过 |

一句话分开：**进程阻塞是「把 CPU 让给别人」，DMA 周期挪用是「CPU 暂时借不出总线」**。前者是软件主动的调度行为，后者是硬件被动的仲裁结果。一次 I/O 里两者可以同时发生，也可能只发生其中一个——轮询方式的 I/O 既不阻塞进程，也用不着 DMA。

### 7.2 磁盘与 RAID

**3. 假定一个程序重复完成将磁盘上一个 4 KB 的数据块读出，进行相应处理后，写回到磁盘的另外一个数据区。各数据块内信息在磁盘上连续存放，并随机地位于磁盘的一个磁道上。磁盘转速为 7200 RPM，平均寻道时间为 10 ms，磁盘最大数据传输率为 40 MBps，磁盘控制器的开销为 2 ms，没有其他程序使用磁盘和处理器，并且磁盘读写操作和磁盘数据的处理时间不重叠。若程序对磁盘数据的处理需要 20000 个时钟周期，处理器时钟频率为 500 MHz，则该程序完成一次数据块“读出一处理—写回”操作所需的时间为多少？每秒钟可以完成多少次这样的数据块操作？**

**答案：** 数据块的平均读取或写回时间为：磁盘控制器开销 + 平均寻道时间 + 平均旋转等待时间 + 数据块读写时间。

磁盘旋转一圈的时间为 $1\ 000/(7\ 200/60) \approx 8.33\ \text{ms}$，故平均旋转等待时间约为 $8.33/2 = 4.17\ \text{ms}$。因为数据块内信息连续，所以，一个数据块的传输时间约为 $4\ \text{K}/(40 \times 10^{6}) = 0.102\ 4\ \text{ms}$，因而数据块平均读取或写回时间为 $2\ \text{ms} + 10\ \text{ms} + 4.17\ \text{ms} + 0.102\ 4\ \text{ms} \approx 16.27\ \text{ms}$。数据块的处理时间为 $20\ 000/500\ \text{M} = 0.04\ \text{ms}$。

因为数据块随机存放在某个磁道上，所以，每个数据块的平均处理时间（包括读出、处理和写回时间）都是相同的，其整个时间为 $16.27\ \text{ms} \times 2 + 0.04\ \text{ms} = 32.58\ \text{ms}$。因此，每秒钟可以完成这样的数据块操作次数大约是 $1000\ \text{ms} / 32.58\ \text{ms} \approx 30$ 次。

**4. 假定有两个 RAID 系统 A 和 B，各自用来存储 10 TB 的数据。系统 A 使用 RAID 1 技术，系统 B 使用 RAID 5 技术。**

（1）系统 A 需要比系统 B 多用多少存储量？

（2）哪个系统更可靠？为什么？

**答案：** （1）系统 A 使用 RAID 1 技术，采用磁盘镜像方式存储，因此所用磁盘容量为 $10+10=20$ TB。系统 B 使用 RAID 5 技术，采用奇偶校验，假设磁盘阵列使用 4 个数据盘和 1 个奇偶校验盘（共 5 个盘），那么 10 TB 的数据需要 2.5 TB 来存放冗余的奇偶校验数据，所以系统 A 比系统 B 多用 7.5 TB 存储容量。

（2）系统 A 更可靠，因为系统对整个磁盘都进行了备份，所以即使所有的数据都损坏了也可以恢复，而系统 B 只是记录了部分冗余信息，如果两个磁盘的相同位都损坏了就恢复不出来了。

### 7.3 总线与 I/O 接口

**5. 假设一个 32 位的处理器连接了一个 32 位宽的处理器总线，总线的时钟频率为 400 MHz，支持多种总线事务类型。其中，最短的总线事务类型是存储器读事务，需要 4 个时钟周期完成，第 1 个时钟周期送地址和读命令，第 4 个时钟周期取数；最长的总线事务类型是突发传送 8 次数据，需要 11 个时钟周期完成，第 1 个时钟周期送地址和读命令，第 4 个时钟周期开始连续传送 8 个数据，每个时钟周期传送一次。请回答下列问题：**

（1）该总线是同步总线还是异步总线，为什么？

（2）该总线的最大数据传输率为多少？

（3）若处理器一直持续发起最短总线事务类型，则此时总线的数据传输率是多少？

（4）若处理器一直持续发起最长总线事务类型，则此时总线的数据传输率是多少？

（5）若将处理器总线的总线宽度扩展为 64 位，则该总线的最大数据传输率提高到多少？

（6）若将处理器总线的总线时钟频率提高到 800 MHz，则该总线的最大数据传输率提高到多少？

（7）加倍总线宽度和加倍总线时钟频率相比，哪种更好？

**答案：** （1）该总线是同步总线，因为所有总线操作都在时钟信号的控制下进行。

（2）总线最大数据传输率就是总线带宽，表示在总线上传输数据时单位时间内传输的最大数据量，它由总线宽度 W、总线时钟频率 F 和一个时钟周期内传输的数据个数 M 确定。其值等于 $W \times F \times M$。根据题意，总线在数据传送阶段，每个时钟能传送一次数据，因此该总线的最大数据传输率为 $32\ \text{b} \times 400\ \text{M} \times 1 = 12.8\ \text{Gb/s} = 1.6\ \text{GB/s}$。

（3）进行最短总线事务类型时，总线数据传输率为 $4\ \text{B} \times 400\ \text{M}/4 = 400\ \text{MB/s}$。

（4）进行最长总线事务类型时，总线数据传输率为 $4\ \text{B} \times 8 \times 400\ \text{M}/11 = 518\ \text{MB/s}$。

（5）若总线宽度扩展一倍，则总线最大数据传输率提高一倍，为 3.2 GB/s。

（6）若总线时钟频率提高一倍，则总线最大数据传输率提高一倍，为 $3.2\ \text{GB/s}$。

（7）加倍总线宽度和加倍总线时钟频率的措施对于总线速度来说，效果是一样的。

**6. 存储器总线采用同步通信方式，假定时钟频率为 $50\ \text{MHz}$，每个总线事务以突发方式传输 8 个字，以支持块长为 8 个字的 cache 行读和 cache 行写，每字 4 字节。对于读操作，访问顺序是 1 个时钟周期接受地址，3 个时钟周期等待存储器读数，8 个时钟周期用于传输 8 个字。对于写操作，访问顺序是 1 个时钟周期接受地址，2 个时钟周期延迟，8 个时钟周期用于传输 8 个字，3 个时钟周期恢复和写入纠错码。**

（1）该存储器总线的带宽是多少？

（2）当全部访问为连续的读操作时，该存储器总线的数据传输率是多少？

（3）当全部访问为连续的写操作时，该存储器总线的数据传输率是多少？

**答案：** （1）根据题意，总线在数据传送阶段，每个时钟能传送一次数据，所以，该存储器总线的总线带宽是 $4\ \text{B} \times 50\ \text{M} \times 1 = 200\ \text{MB/s}$。

（2）读取 8 个字用了 $1+3+8=12$ 个时钟周期，故数据传输率为 $8\times4\ \text{B}/(12\times1/50\ \text{M})=133.3\ \text{MB/s}$。

**7. 若前端总线(FSB)的工作频率为 $1333\ \text{MHz}$（实际时钟频率为 $333\ \text{MHz}$），总线宽度为 64 位，则总线带宽为多少？若存储器总线为三通道总线，总线宽度为 64 位，内存条的型号为 DDR3-1333，则整个存储器总线的总带宽为多少？若内存条型号改为 DDR3-1066，则存储器总线的总带宽又是多少？**

**答案：** 前端总线工作频率为 1333 MHz，说明总线上每秒传送 1333 M 次数据，每次在总线上传送 64 位，因而总线带宽为 $8\ \mathrm{B} \times 1333\ \mathrm{M} = 10.664\ \mathrm{GB}/\mathrm{s}$。若内存条型号为 DDR3-1333，说明存储器总线的工作频率为 1333 MHz，即每秒传送 1333 M 次数据，因而每个通道的带宽为 $8\ \text{B} \times 1333\ \text{M/s} \approx 10.67\ \text{GB/s}$，存储器总线的总带宽为 $3 \times 10.67\ \text{GB/s} = 32\ \text{GB/s}$。

若内存条型号为 DDR3-1066，说明存储器总线的工作频率为 $1066\ \mathrm{MHz}$，即每秒传送 $1066\ \mathrm{M}$ 次数据，因而每个通道的带宽为 $8\ \mathrm{B} \times 1066\ \mathrm{M}/\mathrm{s} \approx 8.5\ \mathrm{GB}/\mathrm{s}$，因此存储器总线的总带宽为 $3 \times 8.5\ \mathrm{GB}/\mathrm{s} = 25.5\ \mathrm{GB}/\mathrm{s}$。

**8. 总线的速度通常指每秒钟传输多少次，例如，QPI 总线的速度单位为 GT/s，表示每秒钟传输多少个 10 亿（1 G = 10⁹）次。若 QPI 总线的时钟频率为 2.4 GHz，则其速度为多少？总带宽是多少 GB/s？QPI 总线的速度也称为 QPI 频率，QPI 频率为 6.4 GT/s 时的总带宽是多少？**

**答案：** QPI 总线是一种基于包传输的串行高速点对点连接协议，有 20 条数据线，其中 16 位是有效数据，4 位用于 CRC 校验，发送方(TX)和接收方(RX)有各自的时钟信号，每个时钟周期传输两次数据，并且发送方和接收方可以同时传输，因此总带宽的计算公式是每秒传输次数 $\times$ 每次传输的有效数据 $\times$ 2。若 QPI 的时钟频率为 2.4 GHz，则速度为 4.8 GT/s，表示每秒钟传输 4.8 G 次数据，即 QPI 频率为 4.8 GT/s。此时总带宽是 4.8 GT/s $\times$ 2 B $\times$ 2 = 19.2 GB/s。

QPI 频率为 $6.4\ \text{GT/s}$ 时的总带宽是 $6.4\ \text{GT/s} \times 2\ \text{B} \times 2 = 25.6\ \text{GB/s}$。

**9. PCI-Express 总线采用串行传输方式，PCI-Express × n 表示具有 n 个通路的 PCI-Express 链路。PCI-Express 1.0 规范支持通路中每个方向的发送或接受速率为 2.5 Gb/s，则 PCI-Express × 8 和 PCI-Express × 32 的总带宽分别为多少？**

**答案：** $2.5\ \mathrm{Gb/s} \times 2 \times \text{通路数} / 10$

**10. 假定采用独立编址方式对 I/O 端口进行编号，那么，必须为处理器设计哪些指令来专门用于进行 I/O 端口的访问？连接处理器的总线必须提供哪些控制信号来表明访问的是 I/O 空间？**

**答案：** 若采用独立编址方式对 I/O 端口进行编号，则主存地址编号和 I/O 端口编号可能会相同，所以，无法利用访存指令来访问 I/O 端口，必须提供专门的输入/输出指令（即 I/O 指令），包括 I/O 读指令（即输入指令）和 I/O 写指令（即输出指令）。在执行 I/O 指令时，CPU 会送出相应的 I/O 读和 I/O 写控制信号，以使和执行访存指令时送出的存储器读和存储器写信号有所区别。

### 7.4 I/O 控制方式

**11. 假设有一个磁盘，每面有 200 个磁道，盘面总存储容量为 1.6 MB (1 M = $10^{6}$)，磁盘旋转一周时间为 25 ms，每道有 4 个区，每两个区之间有一个间隙，磁头通过每个间隙需 1.25 ms。请回答下列问题：**

（1）从该磁盘上读取数据时的最大数据传输率是多少？

（2）假如有人为该磁盘设计了一个与主机之间的接口，磁盘每读出一位，串行送入一个移位寄存器，每当移满 16 位后向处理器发出一个请求交换数据的信号。在处理器响应该请求信号并读取移位寄存器内容的同时，磁盘继续读出一位一位数据并串行送入移位寄存器，如此继续工作。已知处理器在接到请求交换的信号以后，最长响应时间是 3 $\mu$s，那么这样设计的接口能否正确工作？若不能，则应如何改进？

**答案：** （1）磁道容量为 $1.6 \times 10^{6}\ \text{B}/200 = 8000\ \text{B}$，每个数据区的容量为 8 000 B/4 = 2 000 B，转过一个数据区的时间为 $(25 - 1.25 \times 4)\ \text{ms}/4 = 5\ \text{ms}$，因而磁盘的最大数据传输率为 2 000 B/5 ms = $4 \times 10^{5}\ \text{B/s} = 0.4\ \text{MB/s}$。

（2）磁盘传送 1 位的时间为 $10^{6}\ \mu\text{s}/(0.4 \times 10^{6} \times 8) = 0.31\ \mu\text{s} \ll 3\ \mu\text{s}$。因为传送 1 位的时间小于 $3\ \mu\text{s}$，因此，当处理器经过 $3\ \mu\text{s}$ 来读取移位寄存器中的数据时，磁盘已经读出了新的数据位，并将原先请求被读的移位寄存器中的数据冲刷掉了。显然，这样的设计接口不能正确工作。传送一个字（16 位 = 2 B）所用的时间为 $2/(0.4 \times 10^{6}) = 5\ \mu\text{s} > 3\ \mu\text{s}$，所以可以在磁盘接口中增加一个 16 位数据缓冲器。当 16 位移位寄存器装满后，首先送入数据缓冲寄存器，在读出下一个 16 位数据期间，上次读出的 16 位数据从数据缓冲器中被取走。

**12. 假设某计算机带有 20 个终端（每个终端包含一个键盘和一个显示器）同时工作，在运行用户程序的同时，能接受来自任意一个终端输入的字符信息，并将字符回送显示。每一个终端的键盘输入部分有一个数据缓冲寄存器 $RDBRi(i=1\sim20)$，当在键盘上按下某一个键时，相应的字符代码即进入 RDBRi，并使它的“完成”状态标志 $Donei(i=1\sim20)$ 置 1，等处理器把该字符代码取走后，$Donei$ 标志自动清 0。每个终端显示部分也有一个数据缓冲寄存器 $TDBRi(i=1\sim20)$，并有一个 $Readyi(i=1\sim20)$ 状态标志，该状态标志为 1 时，表示相应的 $TDBRi$ 是空着的，准备接收新的输出字符代码，当 $TDBRi$ 接收了一个字符代码后，$Readyi$ 标志被自动清 0，并将字符代码送到终端显示。为了接收终端的输入信息，处理器为每个终端设计了一个指针 $PTRi(i=1\sim20)$ 指向为该终端保留的主存输入缓冲区。处理器采用下列两种方案输入键盘代码，同时回送显示。要求画出 DEVCHC 和 DEVINT 两个程序的流程图。**

（1）每隔一固定时间 T 转入一个状态检查程序 DEVCHC，顺序地检查全部终端是否有任何键盘信息要输入，如果有，则顺序完成之。

（2）允许任何有键盘信息输入的终端向处理器发出中断请求。全部终端采用共同的向量地址，利用它使处理器在响应中断后，转入一个中断服务程序 DEVINT，由后者询问各终端状态标志，并为最先遇到的请求中断的终端服务，然后转向用户程序。

**答案：** 定时查询程序 DEVCHC 和中断服务程序 DEVINT 的流程如下图所示。图中用 (x) 表示 x 的内容，x 可能是存储单元地址或寄存器编号。此外，因为标志 Donei 和 Readyi 由硬件控制自动清 0（复位），所以，流程图中没有对这两个标志进行赋值的操作。程序 DEVINT 的流程图中，如果所有终端都检测不到 Done 标志为 1，则说明所有终端都没有键盘输入，也即都没有中断请求，此时不应进入 DEVINT 处理，因此需报告“出错”。

**13. 某计算机的 CPU 主频为 500 MHz，所连接的某外设的最大数据传输率为 20 kBps，该外设接口中有一个 16 位的数据缓存器，相应的中断服务程序的执行时间为 500 个时钟周期。请回答下列问题**

（1）是否可用中断方式进行该外设的输入输出？若能的话，在该设备持续工作期间，CPU 用于该设备进行输入/输出的时间占整个 CPU 时间的百分比大约为多少？

（2）若该外设的最大数据传输率是 2 MBps，则可否用中断方式进行输入输出？

**答案：** （1）因为该外设接口中有一个 16 位数据缓存器，所以，若用中断方式进行输入/输出的话，可以每 16 位数据进行一次中断请求，因此，中断请求的时间间隔为 $10^{6} \times 2\ \text{B/20}\ \text{kB} = 100\ \mu\text{s}$。对应的中断服务程序的执行时间为 $\left(10^{6}/500\ \text{M}\right)\times500=1\ \mu\text{s}$，因为中断响应过程就是执行一条隐指令的过程，所用时间相对于中断处理时间（即执行中断服务程序的时间）而言，几乎可以忽略不计，因而整个中断响应并处理的时间大约 $1\ \mu\text{s}$ 多一点，远远小于中断请求的间隔时间。因此，可以用中断方式进行该外设的输入输出。

若用中断方式进行该设备的输入/输出，则该设备持续工作期间，CPU 用于该设备进行输入/输出的时间占整个 CPU 时间的百分比大约为 1/100 = 1%。也可以通过考察 1 s 内发出的 500 M 个时钟周期中，有多少时钟周期用于中断处理来计算百分比，其计算公式为 $(10^{6}/100\times500)/500\ \text{M}=1\%$。

（2）若外设的最大传输率为 $2\ \text{MBps}$，则中断请求的时间间隔为 $10^{6} \times 2\ \text{B}/2\ \text{MB} = 1\ \mu\text{s}$。而整个中断响应并处理的时间大约 $1\ \mu\text{s}$ 多一点，中断请求的间隔时间小于中断响应和处理时间，也即中断处理还未结束就会有该外设新的中断请求到来，所以不可以用中断方式进行该外设的输入输出。

**14. 假设计算机中某外设以中断方式进行数据输入/输出，每次中断请求传输一个 32 位数，已知该外设的数据传输率为 500 kB/s，每次传输的 CPU 开销（包括中断响应和处理）为 1000 个时钟周期，CPU 的主频为 500 MHz，则该外设在持续工作期间，CPU 用于其数据传送的时间占整个 CPU 时间的百分比是多少？**

**答案：**（教材附录未收本题解答，以下按题意推导）外设准备 32 位数据的时间为 $10^{6} \times 4\ \text{B}/(500\ \text{kB}) = 8\ \mu\text{s}$。因此，外设每隔 8 μs 发一次中断请求。CPU 响应并处理中断所用时间为 $1000 \times 10^{6} / (500 \times 10^{6}) = 2\ \mu\text{s}$，因此，每次 CPU 花 $2\ \mu\text{s}$ 取走数据后，就去执行其他程序；过 8 μs 后外设又准备好下一个数据，又发中断请求，CPU 响应并处理中断以取走数据，然后又去执行其他程序……如此周而复始，直到所有需要的数据传送完。因此，当外设持续工作时，CPU 用于外设数据传送的时间占 CPU 总时间的百分比是 $2/8 = 0.25 = 25\%$。

**15. 某计算机 CPU 主频为 500 MHz，CPI 为 5。假定某外设的数据传输率为 0.5 MB/s，采用中断方式与主机进行数据传送，传输单位为 32 位，对应的中断服务程序包含 18 条指令，中断响应等其他开销相当于 2 条指令的执行时间。请回答下列问题，要求给出计算过程。**

（1）在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？

（2）当该外设的数据传输率达到 5 MB/s 时，改用 DMA 方式传送数据。假定每次 DMA 传送的块大小为 5 000 B，DMA 预处理和后处理的总开销为 500 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？（假设 DMA 与 CPU 之间没有访存冲突）。

**答案：** （1）中断方式下，外设每备好一个 32 位（4 字节）数据就发一次中断请求，让 CPU 执行中断服务程序把它取走；输出方向同理，接口缓冲一空就申请中断，请 CPU 送新数据进去。一次中断搬一个 32 位字。服务程序本身 18 条指令，中断响应等其他开销折合 2 条，合计按 20 条指令计，CPI 为 5。因此，每次 CPU 用于中断处理（数据传送服务）的时钟周期数为 $5\times18+5\times2=100$。外设的数据传输率为 0.5 MB/s，每次中断传送 32 位数据，占 4 个字节，因此，外设每秒钟申请的中断次数为 0.5 MB/4 B=125000，因而每秒钟内 CPU 用于中断响应和处理的时间开销为 $100\times125000=1250000=12.5\ \text{M}$ 个时钟周期，CPU 的时钟频率为 500 MHz，即 CPU 每秒钟内产生 500 M 个时钟周期，故 CPU 用于外设 I/O 的时间占整个 CPU 时间的百分比为 12.5 M/500 M=2.5%（也可通过考察相邻两次中断请求间隔时间内 CPU 用于中断的时间来计算，即 $100\times1/500\ \mathrm{M})/(4\ \mathrm{B}/0.5\ \mathrm{MB})=2.5\%$）。

（2）当外设数据传输率提高到 5 MB/s 时，一秒钟内产生的 DMA 次数为 5 MB/5 000 B=1 000；每次 DMA 传送前都需要进行 DMA 初始化（预处理），DMA 结束后还要进行中断处理（后处理），已知这两个处理总共需要 500 个时钟周期，所以，CPU 用于 DMA 处理的总开销为 $1\ 000\times500=500\ 000=0.5\ \text{M}$ 个时钟周期；而 CPU 的时钟频率为 500 MHz，即 CPU 每秒钟内产生 500 M 个时钟周期，故 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比为 0.5 M/500 M=0.1%（也可通过考察相邻两次 DMA 请求间隔时间内 CPU 用于该外设 I/O 的时间来计算，即 $(500\times1/500\ \text{M})/(5\ 000\ \text{B}/5\ \text{MB})=0.1\%$）。

**16. 假定一台旧式计算机没有 cache，且所有指令都需使用两个总线周期完成，其中一总线周期用来取指令，另一个总线周期用来访问数据。总线周期为 $250\ \text{ns}$，因而，每条指令的执行时间为 $500\ \text{ns}$。若该计算机配置的磁盘上每个磁道有 16 个 512 字节的扇区，磁盘转一圈的时间是 $8.192\ \text{ms}$，采用周期挪用法进行 DMA 传送。请回答下列问题。**

（1）没有磁盘访问主存时，主存频带空间百分比是多少？

（2）若总线宽度为 16 位，则该计算机指令执行速度降低了百分之几？

**答案：** （1）因为所有指令的每个阶段都要访问主存，所以即使没有磁盘访问主存，CPU 也把主存周期占满了，即主存没有空闲的存储周期。因此，主存频带空闲百分比是 0%。

（2）磁盘的数据传输率为 $10^{3} \times 16 \times 512\ \text{B}/8.192 = 1\ \text{MBps}$。当总线位宽为 16 位时，可以在磁盘每准备好一个 16 位（2 B）数据就发一次 DMA 请求信号，也即 DMA 控制器每隔 2 B/1 MBps = 2 $\mu$s 申请一次数据传送，在 2 $\mu$s 期间 CPU 共执行 2 $\mu$s/500 ns = 4 条指令。因此，每 4 条指令的执行被插入一个总线周期（250 ns），以用于一次磁盘数据传送，也即平均每条指令延长了 250/4 = 62.5 ns。因而，计算机执行指令的速度降低了 62.5/500 = 12.5%。

（3）当总线位宽为 32 位时，DMA 控制器每隔 4 B/1 MBps=4 μs 申请一次数据传送，在 4 $\mu$s 期间 CPU 共执行 4 $\mu$s/500 ns = 8 条指令，因此，每 8 条指令的执行被插入一个总线周期，用于一次数据传送，也即平均每条指令延长了 250/8 = 31.25 ns。因而，计算机执行指令的速度降低了 31.25/500 = 6.25%。

## 8 闭卷复习与跨章联系（补充）
